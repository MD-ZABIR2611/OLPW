Key Concepts

Cells are referenced by column letter and row number.

02

Formulas start with = and can use functions like SUM and AVERAGE.

Key Terms

TermExam definition
Absolute referenceA cell reference that stays fixed when copied, e.g. $A$1.
FunctionA predefined formula such as SUM or IF.
ReplicationCopying a formula to other cells.

Exam Tip

Examiner says

Know VLOOKUP, IF, COUNTIF and SUMIF, and when to use absolute references.

Practice Questions

Recall

1. Write a formula to add cells A1 to A10.

Model answer=SUM(A1:A10).
Application

2. What does =IF(B2>=50,"Pass","Fail") do?

Model answerIt shows Pass if B2 is 50 or more, otherwise Fail.
