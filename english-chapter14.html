Key Concepts

01

Read all instructions and note the marks for each question.

02

Allocate time in proportion to marks.

03

Plan extended writing for five minutes before starting.

04

Proofread for spelling, punctuation and grammar.

02

Key Terms

TermExam definition
Command wordThe instruction word in a question, such as 'explain' or 'summarise'.
Mark schemeThe criteria examiners use to award marks.
ProofreadingChecking writing carefully for errors.
03

Exam Tip

Examiner says

Answer the question actually asked; misreading the task is the most common cause of lost marks.

Practice Questions

Recall

Model answerIn proportion to the marks available for each question.
Application

Model answerIt keeps the answer focused, structured and relevant, saving time later.
