Foundations of Computing

SECTION 03 — CORE THEORY

System Architecture

A computer system processes data using the Input $\rightarrow$ Process $\rightarrow$ Output $\rightarrow$ Storage (IPOS) model. The CPU (Central Processing Unit) is the brain of the computer, responsible for executing instructions.

Von Neumann Architecture

The Von Neumann model stores both data and instructions in the same memory. The CPU fetches them via the bus system. Key components include:

ALU (Arithmetic Logic Unit): Performs mathematical and logical operations.

CU (Control Unit): Directs the operation of the processor by timing and controlling data flow.

Registers: Tiny, ultra-fast storage locations (e.g., Accumulator, Program Counter, MAR, MDR).

Fetch-Decode-Execute Cycle

1. Fetch: The CPU retrieves the next instruction from memory (RAM) using the Program Counter (PC) and Memory Address Register (MAR).

2. Decode: The Control Unit translates the instruction into commands the CPU can understand.

3. Execute: The instruction is carried out (e.g., ALU performs a calculation) and results are stored in the Accumulator.

SECTION 04 — KEY DEFINITIONS

Examination Definitions

HARDWARE: The physical, tangible components of a computer system.

SOFTWARE: The programs and instructions that tell the hardware what to do.

EMBEDDED SYSTEM: A computer system built into a larger device to control a specific function (e.g., washing machine microcontroller).

CLOCK SPEED: The number of instruction cycles the CPU can execute per second, measured in Hertz (Hz).

Tracing the FDE Cycle

Understanding registers is easier by tracing the execution of an instruction. Below is a simplified trace table for fetching an instruction from memory address 100.

1 100 100 ??? Fetch: MAR gets address from PC

SECTION 08 — COMMON MISTAKES

Avoid These Errors

Mistake: Confusing Memory (RAM) with Storage (SSD/HDD).

Correction: RAM is volatile, fast, and holds current data. SSD is non-volatile, slower, and holds permanent files.

Mistake: Saying more cores always makes a computer faster.

Correction: Software must be specifically written to utilize multiple cores. A single-threaded app won't run faster on an 8-core CPU.

SECTION 09 — QUICK REVISION

Fast Facts

  • CU = Control Unit (Directs traffic). ALU = Arithmetic Logic Unit (Does math).
  • Von Neumann stored program concept: instructions and data share memory.
  • FDE = Fetch, Decode, Execute.
  • Cache is faster than RAM but smaller; it holds frequently used data.
SECTION 10 — EXAM QUESTIONS

Test Your Knowledge

Question 1 (Standard)

Describe the role of the Control Unit (CU) in the Fetch-Decode-Execute cycle.

2 marks: The Control Unit retrieves/fetches the instruction from memory. It decodes the instruction into signals that the ALU and other components can understand. It then coordinates the execution of the instruction by sending control signals along control buses.
