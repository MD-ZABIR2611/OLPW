Connecting the World

Computer networks allow devices to share resources and communicate. This chapter covers the types of networks, topologies, hardware, and the protocols that govern data transmission across the internet.

SECTION 03 — CORE THEORY

Network Infrastructure

A LAN (Local Area Network) covers a small geographic area (e.g., a school) and is usually owned by the organization. A WAN (Wide Area Network) covers a large area (e.g., the internet) and typically uses third-party telecom links.

Network Topologies

Star: All devices connect to a central switch. If one cable fails, others work. If the switch fails, the network dies.

Mesh: Every device connects to every other. Highly reliable but expensive and complex to wire.

Bus: All devices share a single backbone cable. Cheap, but collisions occur and backbone failure kills the network.

Packet Switching

Data is broken into small packets. Each packet has a header (source/dest IP, order number) and payload (data). Packets travel independently across the network and are reassembled at the destination. This is efficient and robust—if one line fails, packets take another route.

SECTION 04 — KEY DEFINITIONS

Examination Definitions

PROTOCOL: A set of rules governing the transmission of data.

MAC ADDRESS: A unique physical address assigned to a Network Interface Card (NIC) by the manufacturer. Unchangeable.

IP ADDRESS: A logical address assigned by the network when a device connects. Can change depending on the network.

DNS: Domain Name System. Translates human-readable URLs into IP addresses.

SECTION 06 — TRACE TABLES & LOGIC

DNS Resolution Process

When a user types a URL, the computer must find the IP address of the server. This is the DNS lookup sequence.

STEP ACTION
1User enters URL "example.com" into browser.
2Computer checks local cache for IP. Not found.
3Request sent to configured DNS server.
4DNS server finds IP "93.184.216.34" and returns it.
5Browser sends HTTP request to that IP.
SECTION 07 — EXAM TECHNIQUE

Comparing Topologies

When asked to compare network topologies, always mention reliability, cost, and performance. For example, Star is more expensive due to cabling but performs better than Bus because collisions are minimized.

SECTION 08 — COMMON MISTAKES

Avoid These Errors

Mistake: Saying the Internet and the World Wide Web are the same thing.

Correction: The Internet is the physical global network of cables and routers. The WWW is the collection of web pages (information) accessed via the Internet using HTTP.

Mistake: Confusing MAC addresses and IP addresses.

SECTION 09 — QUICK REVISION

Fast Facts

  • LAN = Local. WAN = Global.
  • Switches connect devices in a LAN. Routers connect networks.
  • Packet Switching breaks data into packets for efficient routing.
  • TCP/IP governs how data is packaged and routed.
SECTION 10 — EXAM QUESTIONS

Test Your Knowledge

Question 1 (Standard)

Explain two advantages of using Packet Switching instead of Circuit Switching for transmitting data across the internet.

2 marks: 1) It allows packets to take different routes, avoiding congestion or broken links (robustness). 2) It is more efficient as multiple users can share the same lines simultaneously rather than dedicating a line to one connection.
