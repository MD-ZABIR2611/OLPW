Algorithms & Problem Solving

CORE
SECTION 01 — CHAPTER OVERVIEW

Computational Thinking

Before writing code, you must plan the solution. This chapter focuses on Computational Thinking—breaking problems down, removing unnecessary details, and designing step-by-step solutions (algorithms) using pseudocode and flowcharts.

SECTION 02 — LEARNING OBJECTIVES

Chapter Goals

  • Define decomposition, abstraction, and pattern recognition.
  • Write standard pseudocode for sequence, selection, and iteration.
  • Draw flowcharts using standard symbols.
  • Construct trace tables to test algorithm logic.
SECTION 03 — CORE THEORY

Problem Solving Principles

Decomposition: Breaking a large problem (e.g., making a game) into smaller, manageable parts (drawing graphics, handling input, calculating scores).

Abstraction: Hiding unnecessary details. E.g., a map app shows roads but hides individual buildings' floor plans. It focuses only on what is needed to solve the problem.

Algorithm Representation

Algorithms can be written in Pseudocode (structured English resembling code) or visualized as Flowcharts. Both use inputs, processes, and outputs.

SECTION 04 — KEY DEFINITIONS

Examination Definitions

ALGORITHM: A step-by-step set of instructions used to solve a problem or perform a task.

SEQUENCE: Instructions executed in order, one after the other.

SELECTION: A decision point (IF/ELSE) where the path changes based on a condition.

ITERATION: The repetition of a block of code (loops).

SECTION 07 — EXAM TECHNIQUE

Pseudocode Standards

Always use standard IGCSE pseudocode keywords: INPUT, OUTPUT or PRINT, WHILE...ENDWHILE, FOR...NEXT, IF...THEN...ELSE...ENDIF. Do not write in Python or Java syntax unless specifically asked for high-level code.

SECTION 08 — COMMON MISTAKES

Avoid These Errors

Mistake: Infinite loops.

Correction: Always ensure the condition in a WHILE loop will eventually become false. If Count never increments, Total never changes, and the loop runs forever.

SECTION 09 — QUICK REVISION

Fast Facts

  • Decomposition = Divide and conquer.
  • Abstraction = Hide details.
  • Sequence = 1, 2, 3. Selection = IF. Iteration = LOOP.
  • Trace tables are used to dry-run algorithms to find logic errors.
SECTION 10 — EXAM QUESTIONS

Test Your Knowledge

Question 1 (Standard)

Write pseudocode for an algorithm that asks the user to input a password. If the password is "Secret", it prints "Access Granted". Otherwise, it prints "Access Denied".

3 marks:

INPUT Password

IF Password == "Secret" THEN

    OUTPUT "Access Granted"

ELSE

    OUTPUT "Access Denied"

ENDIF
