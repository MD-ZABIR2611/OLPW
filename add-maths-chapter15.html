Applications of Differentiation

Turning dy/dx into marks: equations of tangents and normals, classifying stationary points, connected rates of change, and optimising quantities in practical contexts.

Key Concepts

01

The gradient of a curve at a point is the value of dy/dx there, so the tangent at x = a has gradient f′(a) and the normal has gradient −1/f′(a), the negative reciprocal, because the normal is perpendicular to the tangent.

02

A stationary point occurs where dy/dx = 0; the first derivative test classifies it by the sign change of dy/dx — positive to negative gives a maximum, negative to positive gives a minimum.

03

At a stationary point, d²y/dx² < 0 indicates a maximum and d²y/dx² > 0 indicates a minimum; full justification of the conclusion is expected, and points of inflexion are not required.

04

Connected rates of change link two rates with the chain rule, e.g. dv/dt = (dv/dr) × (dr/dt); first establish the geometric or physical relationship between the quantities, then differentiate it with respect to time.

05

Optimisation method: define the variables, use the constraint to express the quantity as a function of one variable, differentiate, solve dy/dx = 0, verify the nature of the stationary point, and give the answer in context with units.

06

For a small change δx, δy ≈ (dy/dx) × δx; this small increment approximation uses the tangent to estimate the change in a function near a known point.

Key Terms

TermExam definition
Stationary pointA point on a curve where the gradient is zero, found by solving dy/dx = 0 and classified using the first or second derivative test.
Maximum pointA stationary point where the gradient changes from positive to negative, so the function changes from increasing to decreasing there.
Minimum pointA stationary point where the gradient changes from negative to positive, so the function changes from decreasing to increasing there.
Second derivative testAt a stationary point, d²y/dx² < 0 indicates a maximum and d²y/dx² > 0 indicates a minimum.
Connected rates of changeTwo or more rates linked by the chain rule, e.g. dv/dt = (dv/dr) × (dr/dt), used when related quantities vary with time together.
OptimisationUsing differentiation to find the maximum or minimum value of a quantity in a practical problem, subject to given constraints.
Normal to a curveThe straight line through a point on a curve perpendicular to the tangent there, with gradient equal to the negative reciprocal of the tangent gradient.
Small increment approximationFor a small change δx in x, the change in y is approximately δy ≈ (dy/dx) × δx, using the tangent to estimate the change.

Exam Tip

Exam tip

When a question asks for the nature of a stationary point, quote the sign change of dy/dx or the sign of d²y/dx² explicitly; in optimisation questions end with the optimal value, its units and a one-line statement of what it represents, because the interpretation mark is separate from the differentiation marks.

Practice Questions

Structured practice — write your answer, then reveal the model.

FOUNDATION

For the curve y = x² − 6x + 4, find the coordinates of the stationary point and determine whether it is a maximum or a minimum.

Model answerdy/dx = 2x − 6; at a stationary point 2x − 6 = 0 so x = 3 (1). When x = 3, y = 9 − 18 + 4 = −5, so the point is (3, −5) (1). d²y/dx² = 2, which is positive (1), so (3, −5) is a minimum point (1).
CHALLENGE

A closed cylindrical can must have volume 500 cm³, so its surface area is A = 2πr² + 1000/r. Find the radius that minimises the surface area, justify that it is a minimum, and explain the practical meaning.

Model answerdA/dr = 4πr − 1000/r²; setting dA/dr = 0 gives 4πr³ = 1000, so r³ = 250/π and r ≈ 4.30 cm (1)(1). d²A/dr² = 4π + 2000/r³, which is positive when r ≈ 4.30, so the stationary point is a minimum (1). Practically, this radius uses the least material to make the can, which cuts production cost (1).
