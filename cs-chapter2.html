Data Representation

CORE
SECTION 01 — CHAPTER OVERVIEW

How Computers Store Information

Computers do not understand human languages or decimal numbers; they only process electrical signals. This chapter explains how real-world data—numbers, text, images, and sound—is converted into binary (0s and 1s) for processing and storage.

SECTION 02 — LEARNING OBJECTIVES

SECTION 03 — CORE THEORY

Number Systems & Media

Binary is base-2 (0 and 1). Denary (Decimal) is base-10 (0-9). Hexadecimal is base-16 (0-9, A-F). Hex is used by humans as a shorthand for binary because one hex digit represents exactly 4 bits (a nibble).

Character Encoding

ASCII: 7-bit code representing English characters (128 characters).

Unicode: 16-bit or 32-bit code representing global characters, emojis, and symbols. Solves ASCII's limitation.

Images & Sound

Images are stored as a grid of pixels. The resolution is the width x height. Colour depth is the number of bits used per pixel. More bits = more possible colours.

Sound is stored by measuring the amplitude of a sound wave at regular intervals (sampling). The sample rate is measurements per second (Hz). The sample resolution is bits per sample.

SECTION 04 — KEY DEFINITIONS

Examination Definitions

BIT: The fundamental unit of data (a 1 or a 0).

NIBBLE: 4 bits.

BYTE: 8 bits.

OVERFLOW: An error that occurs when a calculation produces a number too large for the allocated register/memory space.

SECTION 06 — CALCULATIONS & TRACE TABLES

Image File Size Calculation

Formula: File Size (bits) = Resolution (pixels) × Colour Depth (bits)

// Calculate image file size resolution = 1920 * 1080 // 2,073,600 pixels colour_depth = 24 // 24-bit "True Colour" file_size_bits = resolution * colour_depth file_size_bytes = file_size_bits / 8 PRINT file_size_bytes // Output: 6220800 bytes (~6.2MB)
VARIABLE VALUE CALCULATION
resolution 2,073,600 1920 × 1080
colour_depth 24 Assigned constant
file_size_bits 49,766,400 2,073,600 × 24
file_size_bytes 6,220,800 49,766,400 / 8
SECTION 07 — EXAM TECHNIQUE

Calculation Command Words

If the question asks to "Calculate", you MUST show your working. Always write the formula first, then substitute the numbers, and finally provide the answer with correct units (bits, bytes, KB, MB). If the result is in bits, divide by 8 to get bytes.

SECTION 08 — COMMON MISTAKES

Avoid These Errors

Mistake: Forgetting to divide by 8.

Correction: The formula gives the size in bits. Exam questions usually ask for the answer in bytes or Kilobytes. 8 bits = 1 byte.

Mistake: Confusing Sample Rate (Hz) with Sample Resolution (bits).

SECTION 09 — QUICK REVISION

Fast Facts

  • 1 Hex digit = 4 bits (1 nibble).
  • Image Size = Horizontal Pixels × Vertical Pixels × Colour Depth.
  • Sound Size = Sample Rate × Sample Resolution × Duration (seconds).
  • Lossy compression permanently removes data; Lossless does not.
SECTION 10 — EXAM QUESTIONS

Test Your Knowledge

Question 1 (Standard)

Calculate the file size in Kilobytes (KB) for a sound file that lasts 10 seconds. The sound is recorded at a sample rate of 20,000 Hz and a sample resolution of 16 bits. Show your working.

3 marks:

1. Size (bits) = 20,000 × 16 × 10 = 3,200,000 bits

2. Size (bytes) = 3,200,000 / 8 = 400,000 bytes

3. Size (KB) = 400,000 / 1024 = 390.625 KB
