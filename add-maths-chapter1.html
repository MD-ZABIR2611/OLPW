Functions

How functions map inputs to outputs, and how to find domains, ranges, composite functions, inverse functions and modulus graphs.

01

Overview

Functions are the language of the whole Additional Mathematics course: every later topic, from logarithms to calculus, is written in function notation. In this chapter you will learn to describe a function precisely using its domain and range, to combine functions into composites, and to reverse a function by finding its inverse. You will also meet the modulus function, which turns every negative output into a positive one and produces distinctive V-shaped and reflected graphs. Examiners set at least one question on functions in almost every paper, usually worth six to ten marks, so fluent, accurate notation is essential.

By the end of this chapter you should be able to:

  • Use function notation such as f(x) = 2x + 3 and f : x ↦ 2x + 3 correctly.
  • State the domain and find the range of a function, including functions with restricted domains.
  • Distinguish one-one functions from many-one functions and explain why only one-one functions have inverses.
  • Form composite functions such as fg(x) and gf(x) and solve equations involving them.
  • Find the inverse function f⁻¹(x) algebraically and state its domain and range.
  • Sketch the graph of y = f⁻¹(x) as the reflection of y = f(x) in the line y = x.
  • Sketch graphs of the form y = |f(x)| where f is linear, quadratic or trigonometric.
02

Mappings and Function Notation

A mapping is a rule that links each member of one set (the inputs) to members of another set (the outputs). Mappings can be one-one, where each input has exactly one output and each output comes from exactly one input; many-one, where different inputs can share the same output; one-many, where one input gives several outputs; or many-many. A function is a mapping in which every input in the domain produces exactly one output. This means one-one and many-one mappings are functions, but one-many and many-many mappings are not.

Cambridge uses two equivalent notations. You may see f(x) = x² + 1 or f : x ↦ x² + 1, read as 'f maps x to x² + 1'. The letter x is just a placeholder, so f(3) means replace every x with 3, giving 3² + 1 = 10, and f(2a) means (2a)² + 1 = 4a² + 1. Always substitute with brackets, especially when the input is negative or an expression; f(−3) = (−3)² + 1 = 10, not −9 + 1.

A quick way to test whether a graph represents a function is the vertical line test: if any vertical line meets the graph more than once, one input has several outputs, so it is not a function. A horizontal line test tells you whether a function is one-one: if any horizontal line meets the graph more than once, the function is many-one. For example, y = x² fails the horizontal line test because the line y = 4 meets it at x = 2 and x = −2.

  • One-one: each output comes from exactly one input, e.g. f(x) = 2x − 5.
  • Many-one: at least two inputs share an output, e.g. f(x) = x² for x ∈ ℝ.
  • Only one-one and many-one mappings qualify as functions.
03

Domain and Range

The domain of a function is the set of input values you are allowed to use. It is part of the definition of the function, so the same rule with a different domain is technically a different function. Sometimes the domain is stated, as in f(x) = 3x − 1 for 0 ≤ x ≤ 4. Sometimes you must exclude values that would break the rule: you cannot divide by zero, so g(x) = 5/(x − 2) needs x ≠ 2, and you cannot take the square root of a negative number in real arithmetic, so h(x) = √(x + 3) needs x ≥ −3. Logarithms need positive inputs, so ln(x − 1) requires x > 1.

The range is the set of output values that the function actually produces from its domain. The most reliable method is to sketch the graph over the given domain and read off the lowest and highest y-values. For f(x) = 3x − 1 with 0 ≤ x ≤ 4, the graph is a straight line rising from (0, −1) to (4, 11), so the range is −1 ≤ f(x) ≤ 11. For quadratics, complete the square to find the vertex: f(x) = x² − 6x + 11 = (x − 3)² + 2, so the minimum value is 2 and the range for x ∈ ℝ is f(x) ≥ 2.

Be careful with restricted domains that do not include the vertex, and with functions that have asymptotes. For f(x) = (x − 3)² + 2 with domain x ≥ 5, the function is increasing throughout, so the smallest output is f(5) = 6 and the range is f(x) ≥ 6. For g(x) = e^x + 2, the curve approaches y = 2 but never reaches it, so the range is g(x) > 2 with a strict inequality. Always write the range in terms of f(x) or y, never in terms of x, because the range describes outputs.

Key fact:Domain describes the inputs (x); range describes the outputs (f(x) or y). Write the range using f(x), not x.
04

Composite Functions

A composite function is formed when the output of one function becomes the input of another. The notation fg(x) means f(g(x)): apply g first, then apply f to the result. The order matters because fg(x) and gf(x) are usually different. A useful habit is to read composite notation from right to left, since the function nearest to x acts first. For f(x) = 2x + 1 and g(x) = x², fg(x) = f(x²) = 2x² + 1, whereas gf(x) = g(2x + 1) = (2x + 1)² = 4x² + 4x + 1.

To evaluate a composite at a number, work from the inside out. With the same functions, fg(3) = f(9) = 19 and gf(3) = g(7) = 49. The notation f²(x) means ff(x), the function applied twice, not the square of f(x). So for f(x) = 2x + 1, f²(x) = 2(2x + 1) + 1 = 4x + 3. Examiners often test this, and writing [f(x)]² instead of ff(x) loses all the marks for that part.

A composite fg only exists if every output of g lies inside the domain of f. For example, if f(x) = √x for x ≥ 0 and g(x) = x − 5 for x ∈ ℝ, then g can produce negative outputs, which f cannot accept, so fg is only defined for x ≥ 5. In exam questions you may be asked to state the domain of a composite or explain why a composite cannot be formed; compare the range of the inner function with the domain of the outer function to decide.

Key fact:fg(x) = f(g(x)): g acts first. f²(x) means ff(x), not [f(x)]².
05

Inverse Functions

The inverse function f⁻¹ undoes whatever f does: if f(a) = b then f⁻¹(b) = a, and so ff⁻¹(x) = f⁻¹f(x) = x. An inverse can only exist if f is one-one, because a many-one function would send one output back to several inputs, and that reversed mapping would not be a function. This is why exam questions often restrict the domain of a quadratic, for example f(x) = (x − 2)² for x ≥ 2, so that only one branch of the parabola is used and the function becomes one-one.

The standard algebraic method has three steps. First write y = f(x). Next rearrange to make x the subject. Finally swap the letters so the inverse is written as a function of x. For f(x) = 4x − 7, write y = 4x − 7, rearrange to x = (y + 7)/4, then write f⁻¹(x) = (x + 7)/4. Check your answer by testing a value: f(2) = 1 and f⁻¹(1) = 8/4 = 2, which confirms the inverse is correct.

The domain and range swap roles between a function and its inverse. The domain of f⁻¹ is the range of f, and the range of f⁻¹ is the domain of f. For f(x) = (x − 2)² + 1 with x ≥ 2, the range of f is f(x) ≥ 1. Rearranging y = (x − 2)² + 1 gives x = 2 + √(y − 1), taking the positive root because x ≥ 2. So f⁻¹(x) = 2 + √(x − 1) with domain x ≥ 1 and range f⁻¹(x) ≥ 2. Stating the domain of the inverse is frequently worth a separate mark.

  • Step 1: write y = f(x).
  • Step 2: rearrange to make x the subject, choosing the correct sign of any square root.
  • Step 3: interchange x and y to give f⁻¹(x) and state its domain (the range of f).
06

Graphs of a Function and its Inverse

Because an inverse swaps every point (a, b) on y = f(x) to the point (b, a), the graph of y = f⁻¹(x) is the reflection of the graph of y = f(x) in the line y = x. When sketching both on the same axes, draw the line y = x lightly first, use equal scales on both axes, and reflect key points such as intercepts and end points. If f crosses the y-axis at (0, 3), then f⁻¹ crosses the x-axis at (3, 0).

Any point where y = f(x) meets the line y = x also lies on y = f⁻¹(x), since reflecting it leaves it unchanged. This gives a useful shortcut: for an increasing function, the solutions of f(x) = f⁻¹(x) are the same as the solutions of f(x) = x, which is usually a much simpler equation. For example, with f(x) = 3x − 4 the equation f(x) = x gives 2x = 4, so x = 2, and indeed f⁻¹(2) = (2 + 4)/3 = 2. Use this shortcut only for increasing functions; decreasing functions can have extra intersections off the line y = x.

Exponential and logarithmic functions form an important inverse pair. The function f(x) = e^x has domain x ∈ ℝ and range f(x) > 0, and its inverse is f⁻¹(x) = ln x with domain x > 0 and range f⁻¹(x) ∈ ℝ. Their graphs are reflections of each other in y = x: e^x passes through (0, 1) with asymptote y = 0, and ln x passes through (1, 0) with asymptote x = 0. You will use this pair repeatedly in the logarithms chapter.

Key fact:y = f⁻¹(x) is the reflection of y = f(x) in the line y = x; the point (a, b) becomes (b, a).
07

The Modulus Function and Graphs of y = |f(x)|

The modulus of a number, written |x|, is its size without sign: |5| = 5, |−5| = 5 and |0| = 0. Formally |x| = x when x ≥ 0 and |x| = −x when x < 0. The modulus function therefore never gives a negative output. The graph of y = |x| is a V shape with its vertex at the origin, made from y = x for x ≥ 0 and y = −x for x < 0.

To sketch y = |f(x)|, first sketch y = f(x) lightly. Any part of the curve that lies above the x-axis stays exactly where it is. Any part below the x-axis is reflected in the x-axis so that it lies above it. Points on the x-axis stay fixed. For a linear function such as y = |2x − 3|, the line crosses the x-axis at x = 1.5, so the graph becomes a V with vertex (1.5, 0) and y-intercept |−3| = 3. The reflected part meets the unreflected part at a sharp corner, not a smooth curve.

For quadratics, the part between the roots is usually the part that gets reflected. For y = |x² − 4x − 5| = |(x − 5)(x + 1)|, the roots are x = −1 and x = 5, and the vertex of the original parabola is at (2, −9). After reflecting, the section between the roots becomes an upside-down arch with maximum point (2, 9), and the y-intercept becomes (0, 5). Trigonometric graphs work the same way: y = |sin x| turns every negative hump of the sine wave into a positive hump, so the graph has period 180° instead of 360°.

Modulus graphs are frequently used to count solutions. The number of solutions of |f(x)| = k equals the number of times the horizontal line y = k meets the graph. For y = |x² − 4x − 5|, the line y = k meets the graph four times when 0 < k < 9, three times when k = 9, and twice when k > 9 or k = 0. Questions asking for the set of values of k usually rely on reading off the reflected vertex.

  • Label every x-intercept and y-intercept on a modulus sketch.
  • Show the reflected vertex with its coordinates, e.g. (2, 9).
  • The graph never goes below the x-axis and has sharp corners at the roots.
08

Functions in Exam Questions

Most exam questions on functions combine several skills in one structure. A typical question defines two or three functions with their domains, asks for a range, then a composite, then an inverse, and finally an equation linking them, such as solving fg(x) = f⁻¹(x). Each part usually depends on the previous one, so accuracy early on protects marks later. Keep your algebra tidy, simplify fully, and state domains whenever the function has a restriction.

When solving equations involving composites, always form the composite algebraically first, then set up the equation. Clear fractions by multiplying both sides by the denominators, collect terms to form a quadratic if necessary, and solve by factorising or by the quadratic formula. Finally, check each solution against the domain of the original functions. If f is defined only for x > 0, a negative root of the equation must be rejected, and you should say so explicitly to gain the final accuracy mark.

Sketching questions reward clear labelling more than artistic accuracy. Mark intercepts with their coordinates, indicate asymptotes with dashed lines and their equations, and show end points of restricted domains with coordinates. If you are asked to sketch f and f⁻¹ together, drawing the line y = x makes the symmetry obvious to the examiner and helps you avoid common reflection errors.

Key Terms

TermExam definition
FunctionA mapping in which every element of the domain is mapped to exactly one element of the range.
DomainThe set of input values (x-values) for which a function is defined.
RangeThe set of output values f(x) produced by a function from its domain.
One-one functionA function in which each output corresponds to exactly one input; it passes the horizontal line test.
Many-one functionA function in which two or more different inputs give the same output.
Composite functionA function formed by applying one function to the output of another; fg(x) = f(g(x)), with g applied first.
Inverse functionThe function f⁻¹ that reverses f, so that f⁻¹f(x) = ff⁻¹(x) = x; it exists only if f is one-one.
Self-inverse functionA function that is its own inverse, so f⁻¹(x) = f(x), for example f(x) = 1/x or f(x) = 6 − x.
ModulusThe non-negative size of a number: |x| = x if x ≥ 0 and |x| = −x if x < 0.
AsymptoteA line that a curve approaches more and more closely but never meets.
Restricted domainA domain deliberately limited, for example x ≥ 2, often so that a function becomes one-one and has an inverse.
MappingA rule that links each element of one set to one or more elements of another set.

Worked Examples

Composite functions and an equation

The functions f and g are defined for x ∈ ℝ by f(x) = 2x + 3 and g(x) = x² − 1. (a) Find fg(x) and gf(x). (b) Solve the equation fg(x) = gf(x), giving your answers correct to 3 significant figures.

  1. fg(x) = f(g(x)) = f(x² − 1) = 2(x² − 1) + 3 = 2x² + 1.
  2. gf(x) = g(f(x)) = g(2x + 3) = (2x + 3)² − 1 = 4x² + 12x + 9 − 1 = 4x² + 12x + 8.
  3. Set them equal: 2x² + 1 = 4x² + 12x + 8, so 0 = 2x² + 12x + 7.
  4. Use the quadratic formula: x = [−12 ± √(144 − 56)]/4 = (−12 ± √88)/4 = (−6 ± √22)/2.
  5. Evaluate: √22 ≈ 4.6904, so x ≈ (−6 + 4.6904)/2 = −0.655 or x ≈ (−6 − 4.6904)/2 = −5.35.
fg(x) = 2x² + 1, gf(x) = 4x² + 12x + 8; x = −0.655 or x = −5.35 (3 s.f.).

Inverse of a rational function

The function f is defined by f(x) = (3x − 1)/(x + 2) for x ≠ −2. Find f⁻¹(x) and state the value of x for which f⁻¹ is not defined.

  1. Write y = (3x − 1)/(x + 2) and multiply both sides by (x + 2): y(x + 2) = 3x − 1.
  2. Expand: xy + 2y = 3x − 1. Collect the x terms on one side: xy − 3x = −1 − 2y.
  3. Factorise: x(y − 3) = −(1 + 2y), so x = (1 + 2y)/(3 − y).
  4. Interchange x and y: f⁻¹(x) = (2x + 1)/(3 − x).
  5. Check with a value: f(1) = 2/3 and f⁻¹(2/3) = (4/3 + 1)/(3 − 2/3) = (7/3)/(7/3) = 1, which confirms the result.
f⁻¹(x) = (2x + 1)/(3 − x), which is not defined when x = 3 (the value that f never takes).

Range and inverse of a quadratic with restricted domain

The function f is defined by f(x) = x² − 4x + 1 for x ≥ 2. (a) Find the range of f. (b) Find an expression for f⁻¹(x) and state its domain.

  1. Complete the square: x² − 4x + 1 = (x − 2)² − 4 + 1 = (x − 2)² − 3.
  2. The vertex is (2, −3) and the domain starts at x = 2, so f is increasing for all x ≥ 2. Range: f(x) ≥ −3.
  3. Write y = (x − 2)² − 3, so (x − 2)² = y + 3 and x − 2 = ±√(y + 3).
  4. Since x ≥ 2, take the positive root: x = 2 + √(y + 3).
  5. Interchange letters: f⁻¹(x) = 2 + √(x + 3). Its domain is the range of f, namely x ≥ −3.
Range f(x) ≥ −3; f⁻¹(x) = 2 + √(x + 3) for x ≥ −3.

Common Mistakes & Exam Tips

Common mistakes

  • Treating fg(x) as 'f first, then g'. Remember fg(x) = f(g(x)), so g acts first; read composite notation from right to left.
  • Writing f²(x) as [f(x)]². In function notation f²(x) means ff(x), so for f(x) = x + 3, f²(x) = x + 6, not x² + 6x + 9.
  • Stating the range in terms of x, such as x ≥ 2. The range describes outputs, so write f(x) ≥ 2 or y ≥ 2.
  • Taking the wrong sign of a square root when finding an inverse. Use the domain of f to decide: if x ≥ 2, use +√; if x ≤ 2, use −√.
  • Forgetting to state the domain of an inverse. The domain of f⁻¹ is the range of f, and this often carries its own mark.
  • Reflecting the whole graph when sketching y = |f(x)|. Only the parts below the x-axis are reflected; parts above stay exactly where they are.

Exam tips

  • Always check an inverse by substituting a number: if f(a) = b, confirm that f⁻¹(b) = a before moving on.
  • Complete the square for any quadratic function; it gives the vertex, the range and the correct restricted domain for an inverse in one step.
  • When asked for the largest domain of the form x ≥ k for which an inverse exists, k is the x-coordinate of the vertex.
  • For f(x) = f⁻¹(x) with an increasing function, solve f(x) = x instead; it is quicker and gives the same answers.
  • In modulus sketches, label intercepts and the reflected turning point with coordinates, and draw sharp corners at the x-intercepts.
  • Reject solutions that fall outside the stated domain and write a short reason, for example 'x = −3 rejected since x > 0'.

1. Explain why the function f(x) = x², x ∈ ℝ, does not have an inverse.

Model answerf is many-one (not one-one): for example f(2) = f(−2) = 4 [1]. An inverse would map 4 to two values, so it would not be a function [1].
[2 marks]

2. Given f(x) = 5 − 2x, find f⁻¹(x) and hence f⁻¹(1).

Model answery = 5 − 2x gives x = (5 − y)/2, so f⁻¹(x) = (5 − x)/2 [1]. f⁻¹(1) = 4/2 = 2 [1].

3. State the range of f(x) = 3 − x² for x ∈ ℝ.

Model answerSince x² ≥ 0, the maximum value is 3, so the range is f(x) ≤ 3 [1].

4. Given f(x) = √(x + 1) for x ≥ −1 and g(x) = x² + 3 for x ∈ ℝ, find gf(x) and fg(x) in their simplest forms.

Model answergf(x) = (√(x + 1))² + 3 = x + 4 for x ≥ −1 [1][1]. fg(x) = √(x² + 3 + 1) = √(x² + 4) [1].

5. Given f(x) = 2x − 1 and g(x) = 3/x for x ≠ 0, solve fg(x) = 5.

Model answerfg(x) = 2(3/x) − 1 = 6/x − 1 [1]. 6/x − 1 = 5 gives 6/x = 6 [1], so x = 1 [1].

6. Sketch the graph of y = |2x − 3|, stating the coordinates of the points where the graph meets the axes.

Model answerV-shaped graph with vertex on the x-axis [1] at (1.5, 0) [1]; meets the y-axis at (0, 3) [1]. Both arms are straight lines of gradient ±2.

7. The function f is defined by f(x) = e^(2x) + 1 for x ∈ ℝ. State the range of f and find f⁻¹(x), giving its domain.

Model answerRange f(x) > 1 [1]. y − 1 = e^(2x), so 2x = ln(y − 1) and x = ½ ln(y − 1) [1]. f⁻¹(x) = ½ ln(x − 1) with domain x > 1 [1].
[4 marks]

8. The function f(x) = x² + 2x − 3 is defined for x ≥ k. (a) Find the least value of k for which f has an inverse. (b) Using this value of k, find f⁻¹(x) and state its domain.

Model answer(a) f(x) = (x + 1)² − 4, vertex at x = −1, so k = −1 [1]. (b) y + 4 = (x + 1)², x + 1 = +√(y + 4) since x ≥ −1 [1], f⁻¹(x) = −1 + √(x + 4) [1], domain x ≥ −4 [1].
[3 marks]

9. Given f(x) = 1/(x − 1) for x ≠ 1, find ff(x) as a single fraction, stating any value of x for which it is undefined.

Model answerff(x) = 1/[1/(x − 1) − 1] [1] = 1/[(1 − (x − 1))/(x − 1)] = (x − 1)/(2 − x) [1]. Undefined at x = 1 and x = 2 [1].
[3 marks]

10. The function f is defined by f(x) = 3x − 4. Solve the equation f(x) = f⁻¹(x).

Model answerf⁻¹(x) = (x + 4)/3 [1]. 3x − 4 = (x + 4)/3 gives 9x − 12 = x + 4 [1], so 8x = 16 and x = 2 [1]. (Alternatively solve f(x) = x.)
[3 marks]

11. Sketch y = |(x − 1)(x − 5)| and hence find the set of values of k for which |(x − 1)(x − 5)| = k has exactly four solutions.

Model answerGraph meets the x-axis at (1, 0) and (5, 0) and the y-axis at (0, 5) [1]. The vertex (3, −4) is reflected to (3, 4) [1]. Four solutions when 0 < k < 4 [1].
[6 marks]

12. The functions f and g are defined by f(x) = 4x − 3 for x ∈ ℝ and g(x) = 2/(x + 1) for x ≠ −1. (a) Find f⁻¹(x). (b) Find gf(x) in its simplest form. (c) Solve the equation gf(x) = f⁻¹(x).

Model answer(a) f⁻¹(x) = (x + 3)/4 [1]. (b) gf(x) = 2/(4x − 3 + 1) = 2/(4x − 2) = 1/(2x − 1) [1][1]. (c) 1/(2x − 1) = (x + 3)/4 gives 4 = (x + 3)(2x − 1) = 2x² + 5x − 3 [1], so 2x² + 5x − 7 = 0 and (2x + 7)(x − 1) = 0 [1], x = 1 or x = −3.5 [1].

Quick Recap

  1. A function maps every input in its domain to exactly one output; one-one and many-one mappings are functions.
  2. The domain is the set of allowed inputs and the range is the set of outputs, written in terms of f(x).
  3. fg(x) means f(g(x)), so g is applied first, and f²(x) means ff(x).
  4. Only one-one functions have inverses; restricting the domain of a quadratic to one side of its vertex makes it one-one.
  5. To find f⁻¹, write y = f(x), make x the subject and swap x and y; the domain of f⁻¹ is the range of f.
  6. The graph of y = f⁻¹(x) is the reflection of y = f(x) in the line y = x.
  7. To sketch y = |f(x)|, reflect in the x-axis only the parts of y = f(x) that lie below the axis.
  8. Horizontal lines on a modulus graph show how many solutions an equation |f(x)| = k has.
