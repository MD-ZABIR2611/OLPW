Equations, Inequalities and Graphs

Solving modulus equations and inequalities, using substitution to reveal hidden quadratics, and sketching cubic graphs to solve cubic inequalities.

01

Overview

This chapter extends your equation-solving toolkit beyond straightforward quadratics. You will solve equations and inequalities involving the modulus function, both algebraically and with graphs, and learn to spot equations that are really quadratics in disguise, such as 4^x − 6(2^x) + 8 = 0. You will also sketch cubic curves written as a product of linear factors, sketch their modulus graphs and use them to solve cubic inequalities. These questions reward careful checking, because modulus and substitution methods often generate answers that must be rejected.

By the end of this chapter you should be able to:

  • Solve equations of the form |ax + b| = c and |ax + b| = |cx + d| algebraically and graphically.
  • Solve inequalities of the form |ax + b| < c and |ax + b| > |cx + d|.
  • Check solutions of modulus equations and reject any that do not satisfy the original equation.
  • Use a substitution to form and solve a quadratic equation in order to solve a related equation.
  • Solve simultaneous equations where one equation is linear and the other is non-linear.
  • Sketch cubic graphs of the form y = k(x − a)(x − b)(x − c) and their modulus graphs.
  • Solve cubic inequalities using a sketch of the cubic graph.
02

Modulus Equations

Recall that |A| = c means A is a distance c from zero, so A = c or A = −c (provided c ≥ 0). This gives a direct method for equations such as |2x − 5| = 7: write 2x − 5 = 7, giving x = 6, or 2x − 5 = −7, giving x = −1. If c is negative, the equation has no solutions at all, because a modulus can never be negative; for example |x + 4| = −2 has no solution.

For equations with a modulus on both sides, |A| = |B| means A = B or A = −B. For |2x − 1| = |x + 4|, the first case 2x − 1 = x + 4 gives x = 5, and the second case 2x − 1 = −(x + 4) gives 3x = −3, so x = −1. An alternative is to square both sides, since both sides are non-negative: (2x − 1)² = (x + 4)² gives 4x² − 4x + 1 = x² + 8x + 16, so 3x² − 12x − 15 = 0, which simplifies to (x − 5)(x + 1) = 0. Both methods give the same answers.

When one side is not a modulus, such as |x − 3| = 2x, you must check every answer. The case x − 3 = 2x gives x = −3, but then the right-hand side is 2(−3) = −6, which is negative, while the left-hand side is |−6| = 6. So x = −3 must be rejected. The case x − 3 = −2x gives x = 1, and checking, |1 − 3| = 2 = 2(1), so x = 1 is the only solution. Examiners award a mark specifically for rejecting the invalid root.

Key fact:|A| = |B| ⇔ A = B or A = −B ⇔ A² = B².
03

Modulus Inequalities

Inequalities with a single modulus and a constant can be written without the modulus. |A| < c means −c < A < c, so the expression is within c of zero. For |2x − 5| < 3, write −3 < 2x − 5 < 3, add 5 throughout to get 2 < 2x < 8, and divide by 2 to get 1 < x < 4. In contrast, |A| > c means A < −c or A > c. For |x + 1| ≥ 4, x + 1 ≤ −4 or x + 1 ≥ 4, so x ≤ −5 or x ≥ 3.

For inequalities with a modulus on each side, such as |2x + 1| ≥ |x − 4|, squaring is the most reliable method because both sides are non-negative and squaring preserves the inequality. This gives 4x² + 4x + 1 ≥ x² − 8x + 16, so 3x² + 12x − 15 ≥ 0 and x² + 4x − 5 ≥ 0. Factorising, (x + 5)(x − 1) ≥ 0, so the solution is x ≤ −5 or x ≥ 1. You can check with a test value: x = 0 gives |1| ≥ |−4|, which is false, and 0 is indeed excluded.

A graphical approach helps you see why the answer looks the way it does. Sketch both V-shaped graphs on the same axes, find their intersection points by solving the corresponding equation, then read off where one graph lies above the other. This is especially useful when one side is a modulus and the other is a straight line that is not a modulus, since squaring cannot be used safely unless both sides are known to be non-negative.

  • |A| < c ⇔ −c < A < c.
  • |A| > c ⇔ A < −c or A > c.
  • |A| < |B| ⇔ A² < B², then solve the quadratic inequality.
04

Hidden Quadratics and Substitution

Some equations are not quadratics in x but become quadratics after a substitution. The key is to spot one term that is the square of another. In x − 5√x + 6 = 0, the term x is (√x)², so let u = √x to get u² − 5u + 6 = 0. This factorises as (u − 2)(u − 3) = 0, so u = 2 or u = 3. Since u = √x, x = 4 or x = 9. Always convert back to the original variable at the end; giving u = 2 and u = 3 as the final answer loses the accuracy marks.

Exponential equations frequently hide quadratics too. Since 4^x = (2²)^x = (2^x)², the equation 4^x − 6(2^x) + 8 = 0 becomes u² − 6u + 8 = 0 with u = 2^x. This gives u = 2 or u = 4, so 2^x = 2 or 2^x = 4, leading to x = 1 or x = 2. Similarly 9^x = (3^x)² and e^(2x) = (e^x)². When a value of u is negative, such as 2^x = −3, reject it, because an exponential function is always positive.

Other useful substitutions include u = x² for equations such as x⁴ − 13x² + 36 = 0, which gives (u − 4)(u − 9) = 0, so x² = 4 or 9 and x = ±2 or ±3, giving four solutions. For equations with fractional powers such as 2x^(2/3) − 5x^(1/3) + 2 = 0, let u = x^(1/3). Rejecting impossible values of u, such as a negative value of √x, is an important part of the working.

Key fact:Look for a term that is the square of another: x and √x, 4^x and 2^x, x⁴ and x², e^(2x) and e^x.
05

Simultaneous Equations: One Linear, One Non-linear

When one equation is linear and the other is non-linear, rearrange the linear equation to make one variable the subject, then substitute into the non-linear equation. This produces a quadratic in a single variable. For x + y = 5 and x² + y² = 13, write y = 5 − x, then x² + (5 − x)² = 13. Expanding gives 2x² − 10x + 25 = 13, so 2x² − 10x + 12 = 0 and x² − 5x + 6 = 0. Hence x = 2 or x = 3, and the solutions are (2, 3) and (3, 2).

Always find both coordinates and pair them correctly. A quadratic usually gives two x-values, and each must be substituted back into the linear equation to find its matching y-value. Presenting the answers as coordinate pairs, or as 'x = 2, y = 3 and x = 3, y = 2', makes it clear which values belong together. If the linear equation contains fractions, choose to make whichever variable gives the simplest substitution the subject.

Geometrically, these solutions are the intersection points of a line with a curve, exactly as in the previous chapter. If the resulting quadratic has a zero discriminant, the line is a tangent and there is only one solution pair; if the discriminant is negative, the line and curve do not meet and there are no real solutions. Questions sometimes ask for the length or midpoint of the chord joining the two points, which uses the coordinate geometry formulas from a later chapter.

06

Sketching Cubic Graphs

A cubic function has x³ as its highest power. When it is given in factorised form, y = k(x − a)(x − b)(x − c), the roots are x = a, b and c, so the graph meets the x-axis at these points. The y-intercept is found by setting x = 0. The sign of k decides the overall shape: if k > 0, the graph starts at the bottom left and ends at the top right; if k < 0, it starts at the top left and ends at the bottom right. Between the roots the curve bends, producing a local maximum and a local minimum.

For example, y = (x + 2)(x − 1)(x − 3) has roots x = −2, 1 and 3. Its y-intercept is (2)(−1)(−3) = 6, so it passes through (0, 6). Since k = 1 > 0, the graph comes up from the bottom left, crosses at x = −2, rises to a maximum, falls through (0, 6) and crosses at x = 1, reaches a minimum, then crosses at x = 3 and rises to the top right.

A squared factor means a repeated root, and the graph touches the x-axis there instead of crossing it. For y = (x − 1)²(4 − x), the roots are x = 1 (repeated) and x = 4. The y-intercept is (1)(4) = 4. Expanding the leading term gives −x³, so the graph starts top left, comes down to touch the axis at (1, 0), rises to a maximum, then falls to cross at (4, 0) and continues down to the bottom right.

  • Mark each root on the x-axis and the y-intercept with coordinates.
  • k > 0: bottom left to top right. k < 0: top left to bottom right.
  • A squared factor (x − a)² makes the graph touch the axis at x = a.
  • The curve must be smooth, with no sharp corners.
07

Cubic Inequalities and Modulus Cubic Graphs

Once the cubic is sketched, inequalities follow by reading where the graph is above or below the x-axis. For (x + 2)(x − 1)(x − 3) ≤ 0, the graph is on or below the axis to the left of x = −2 and between x = 1 and x = 3. The solution is therefore x ≤ −2 or 1 ≤ x ≤ 3. Test values confirm this: at x = 0 the expression equals 6, which is positive and correctly excluded; at x = 2 it equals (4)(1)(−1) = −4, which is negative and correctly included.

The syllabus also asks you to solve inequalities of the form k(x − a)(x − b)(x − c) ≤ d graphically. Draw the horizontal line y = d on the sketch, find where it meets the cubic, often by reading from an accurate graph or by being given the intersection points, and identify the x-values for which the curve lies below the line. The same reasoning applies: the curve and line divide the x-axis into intervals, and you choose the intervals that satisfy the inequality.

To sketch y = |k(x − a)(x − b)(x − c)|, draw the cubic and reflect the parts below the x-axis upwards, just as for linear and quadratic moduli. The resulting graph never goes below the x-axis, has sharp corners at the roots where the curve crossed the axis, and stays smooth at a repeated root where the curve only touched the axis. The y-intercept becomes the modulus of the original y-intercept.

Key fact:Solve cubic inequalities from a sketch: find the roots, decide the end behaviour from the sign of k, then read off the intervals.
08

Graphical Methods and Counting Solutions

Graphs give a quick way to find the number of solutions of an equation without solving it. Rewrite the equation as f(x) = g(x), sketch y = f(x) and y = g(x) on the same axes and count the intersection points. For example, the number of solutions of |2x − 4| = x + 1 is the number of times the line y = x + 1 meets the V-shaped graph y = |2x − 4|, which has vertex (2, 0). Since the line passes above the vertex with gradient 1, less steep than either arm, it meets each arm once, giving two solutions.

Algebraically, those two solutions come from the two cases. The first case 2x − 4 = x + 1 gives x = 5, and the second case 2x − 4 = −(x + 1) gives 3x = 3, so x = 1. Both are valid because x + 1 is positive at each. The graph also shows immediately that |2x − 4| < x + 1 for 1 < x < 5, the region where the V lies below the line.

Combining algebra and graphs in this way is the safest approach for harder questions. The sketch tells you how many answers to expect and roughly where they are, while the algebra gives exact values. If your algebra produces a solution that the sketch shows cannot exist, you know to reject it or to look for an error in your working.

Key Terms

TermExam definition
Modulus equationAn equation containing the absolute value of an expression, such as |2x − 1| = |x + 4|.
Modulus inequalityAn inequality containing the absolute value of an expression, such as |2x − 5| < 3.
Critical valueA boundary value found by solving the corresponding equation, used to split the number line for an inequality.
SubstitutionReplacing an expression such as 2^x or √x by a single letter u to turn an equation into a simpler form, usually a quadratic.
Hidden quadraticAn equation that becomes quadratic after substitution, e.g. 4^x − 6(2^x) + 8 = 0 with u = 2^x.
Cubic functionA polynomial function whose highest power of x is 3, such as y = (x + 2)(x − 1)(x − 3).
Repeated rootA root that corresponds to a squared factor; the graph touches, rather than crosses, the x-axis there.
Leading coefficientThe coefficient of the highest power of x; its sign determines the end behaviour of a polynomial graph.
End behaviourThe direction of a graph as x becomes very large positive or very large negative.
Simultaneous equationsTwo or more equations that must be satisfied by the same values of the variables at the same time.
Rejected solutionA value produced by the algebra that does not satisfy the original equation or its conditions and must be discarded.
Intersection pointA point that lies on two graphs at once; its coordinates satisfy both equations.

Worked Examples

Modulus equation with moduli on both sides

Solve the equation |2x − 1| = |x + 4|.

  1. Both sides are non-negative, so square: (2x − 1)² = (x + 4)².
  2. Expand: 4x² − 4x + 1 = x² + 8x + 16.
  3. Rearrange: 3x² − 12x − 15 = 0, and divide by 3: x² − 4x − 5 = 0.
  4. Factorise: (x − 5)(x + 1) = 0, so x = 5 or x = −1.
  5. Check: x = 5 gives |9| = |9|; x = −1 gives |−3| = |3|. Both are valid.
x = 5 or x = −1.

Modulus inequality by squaring

Solve the inequality |x − 2| < |2x + 5|.

  1. Square both sides: (x − 2)² < (2x + 5)², so x² − 4x + 4 < 4x² + 20x + 25.
  2. Rearrange: 0 < 3x² + 24x + 21, and divide by 3: x² + 8x + 7 > 0.
  3. Factorise: (x + 1)(x + 7) > 0, with critical values x = −7 and x = −1.
  4. A U-shaped graph is positive outside the roots, so x < −7 or x > −1.
  5. Check with x = 0: |−2| = 2 < |5| = 5, true. With x = −3: |−5| = 5 < |−1| = 1, false, so −3 is correctly excluded.
x < −7 or x > −1.

Exponential equation as a hidden quadratic

Solve the equation 4^x − 6(2^x) + 8 = 0.

  1. Note that 4^x = (2^x)². Let u = 2^x, so the equation becomes u² − 6u + 8 = 0.
  2. Factorise: (u − 2)(u − 4) = 0, so u = 2 or u = 4.
  3. Return to x: 2^x = 2 gives x = 1; 2^x = 4 = 2² gives x = 2.
  4. Check x = 1: 4 − 12 + 8 = 0. Check x = 2: 16 − 24 + 8 = 0.
x = 1 or x = 2.

Common Mistakes & Exam Tips

Common mistakes

  • Forgetting the negative case of a modulus equation. |A| = c gives A = c or A = −c, so there are usually two cases to solve.
  • Not checking solutions of equations like |x − 3| = 2x. A solution that makes the non-modulus side negative must be rejected.
  • Squaring both sides of |A| < B when B might be negative. Only square when both sides are known to be non-negative.
  • Stopping at u = 2 and u = 4 after a substitution. Always convert back to the original variable x.
  • Accepting impossible values such as 2^x = −3 or √x = −2. Exponentials and principal square roots are never negative.
  • Drawing a cubic that crosses the axis at a repeated root. A squared factor means the curve touches the axis and turns back.

Exam tips

  • For |A| = |B| or |A| < |B|, squaring both sides turns the problem into a standard quadratic equation or inequality.
  • Write 'reject' next to any invalid solution with a short reason; this is often worth a mark.
  • Before sketching a cubic, list the roots, the y-intercept and the sign of the x³ term so nothing is missed.
  • Use a test value inside each interval to confirm your inequality answer, especially for cubics.
  • In substitution questions, state your substitution clearly, e.g. 'Let u = 3^x', so the examiner can follow your method.
  • Sketch a quick graph for modulus questions to predict how many solutions you should find.

Quick Recap

  1. |A| = c gives A = ±c, and |A| = |B| gives A = ±B, which can also be solved by squaring.
  2. |A| < c means −c < A < c, while |A| > c means A < −c or A > c.
  3. Always check modulus solutions and reject any that make a non-modulus side negative.
  4. Substitutions such as u = √x, u = 2^x or u = x² turn hidden quadratics into standard ones; convert back to x at the end.
  5. For one linear and one non-linear equation, substitute the linear equation into the other and pair the solutions correctly.
  6. A cubic y = k(x − a)(x − b)(x − c) crosses the axis at a, b and c; its end behaviour depends on the sign of k.
  7. Cubic inequalities are solved by reading intervals from a sketch, and |f(x)| graphs reflect negative parts upward.
