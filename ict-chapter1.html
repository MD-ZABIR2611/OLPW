Types and Components of Computer Systems

An introduction to hardware and software, the main internal components of a computer, operating systems and user interfaces, the different types of computer and the emerging technologies changing how we use them.

01

Overview

Every question in IGCSE ICT assumes you understand what a computer system is made of and how its parts work together. This chapter builds that foundation by separating hardware from software, explaining what the processor, RAM, ROM and backing storage actually do, and comparing the ways users communicate with a computer through different interfaces. You will also compare desktop and mobile computers and look at emerging technologies such as artificial intelligence and extended reality. Examiners regularly ask you to give advantages and disadvantages of these systems, so learning to compare rather than simply describe is the key skill here.

By the end of this chapter you should be able to:

  • Define hardware and software and give examples of internal and external hardware.
  • Distinguish between application software and system software, giving examples of each.
  • Describe the roles of the CPU, RAM, ROM and backing storage in a computer system.
  • Compare command line, graphical, dialogue-based and gesture-based user interfaces.
  • Describe the features, advantages and disadvantages of desktop, laptop, tablet and smartphone computers.
  • Explain how analogue data is converted to digital data and why this is needed.
  • Describe emerging technologies such as artificial intelligence, augmented reality and virtual reality and their impact.
02

Hardware and Software

A computer system is made up of hardware and software working together. Hardware is the general term for the physical components that make up a computer system, the parts you can see and touch. Internal hardware sits inside the case and includes the motherboard, the central processing unit (CPU), random access memory (RAM), read-only memory (ROM), the graphics card, the sound card, the network interface card (NIC), the power supply and the internal hard disk drive or solid state drive. External hardware, often called peripherals, includes the monitor, keyboard, mouse, printer, external storage and speakers.

Software is the programs, instructions and data that control the operation of a computer. Software cannot be touched; it exists as stored instructions. Without software, hardware is useless, and without hardware, software has nothing to run on. Software is divided into two broad types. Application software allows a user to carry out a specific task, such as writing a letter, editing a photo or managing a database. System software manages the computer hardware and provides a platform on which application software can run.

Examples of application software include word processors for producing documents, spreadsheets for calculations and modelling, database management systems for storing and searching records, control and measuring software, applets and apps, photo editing, video editing and graphics manipulation software, and audio editing software. Examples of system software include the operating system, compilers, interpreters, linkers, device drivers and utility programs. Utilities are small programs that help maintain the computer, such as anti-virus software, disk defragmenters, backup software, file compression tools, disk formatters and screensavers.

  • Compiler: translates a whole high-level language program into machine code in one go, producing an executable file.
  • Linker: combines separately compiled object files into a single executable program.
  • Device driver: software that allows the operating system to communicate with a specific hardware device, such as a printer.
  • Utility: a program that performs a maintenance task, such as anti-virus scanning, defragmentation or backing up.
Key fact:Hardware = physical parts you can touch. Software = programs that tell the hardware what to do.
03

The Main Components of a Computer

The central processing unit (CPU), also called the processor or microprocessor, is the part of the computer that interprets and executes the commands from hardware and software. It carries out calculations, makes logical decisions and controls the flow of data around the system. Inside the CPU are the control unit, which coordinates the fetching and decoding of instructions, and the arithmetic logic unit (ALU), which performs calculations and logical comparisons. Modern CPUs are placed on a single integrated circuit and are measured by clock speed in gigahertz and the number of cores.

Internal memory consists of RAM and ROM. RAM is volatile, meaning its contents are lost when the power is turned off. It holds the operating system, the programs currently running and the data currently in use, and it can be both read from and written to. ROM is non-volatile, so its contents are kept when the power is off. It is usually read-only and stores the start-up instructions, known as the BIOS or boot program, that the computer needs to load the operating system when it is switched on.

Backing storage is non-volatile storage used to keep programs and data permanently, such as hard disk drives, solid state drives, USB flash drives and optical discs. Backing storage has a much larger capacity than RAM and is cheaper per gigabyte, but it is slower to access. Input devices allow data to be entered into the computer, output devices present the results of processing to the user, and together with the CPU and memory they make up the basic model of a computer system: input, process, output and storage.

  • RAM: volatile, read and write, stores data and programs currently in use, larger capacity than ROM.
  • ROM: non-volatile, read only, stores the BIOS and start-up instructions, small capacity.
  • Backing storage: non-volatile, very large capacity, slower than RAM, stores files permanently.
Key fact:RAM is volatile (lost when power is off); ROM is non-volatile (kept when power is off).
04

Operating Systems and User Interfaces

The operating system (OS) is the most important system software. It manages the hardware, controls input and output devices, handles memory and file management, runs applications, deals with security such as user accounts and passwords, handles interrupts and errors, and provides a user interface. Common examples are Microsoft Windows, macOS, Linux, Android and iOS. The user interface is the way the user communicates with the computer, and there are four types you need to know: command line interface, graphical user interface, dialogue-based interface and gesture-based interface.

A command line interface (CLI) requires the user to type instructions, such as commands to copy or delete files, in a precise syntax. It uses very little memory and processing power and gives experienced users direct, powerful control over the computer, but the user must learn and remember many commands, and a single typing error causes the command to fail. A graphical user interface (GUI) uses windows, icons, menus and a pointer (WIMP), or on touch screens a post-WIMP design where fingers replace the pointer. GUIs are intuitive and easy for beginners, but they use far more memory and processing power.

A dialogue-based interface uses the human voice to give commands, as with smart speakers, voice assistants on phones and in-car systems that let a driver change the music or make a call hands-free. It is safer when driving and useful for people with limited movement, but it can misunderstand accents or struggle with background noise. A gesture-based interface detects physical movements of the hands or body using cameras and sensors, such as waving to scroll or swiping in the air. It is natural and needs no contact, but accidental movements may be misread as commands.

Key fact:WIMP = Windows, Icons, Menus, Pointer. Post-WIMP = touch screen gestures such as pinch and swipe.
05

Types of Computer

A desktop computer is designed to stay in one place on a desk, with separate monitor, keyboard and mouse. Desktops are cheaper for the same processing power, easier to upgrade and repair because standard parts can be swapped, have better cooling and so can use more powerful processors, and have full-sized keyboards that are more comfortable for long use. However, they are not portable, they need a constant mains power supply and they take up more desk space. They are often used in offices, schools and for high-end gaming and video editing.

Mobile computers include laptops, tablets, smartphones and phablets. A laptop combines screen, keyboard, touchpad and battery in one portable unit; it can be used anywhere but has a limited battery life, can be stolen easily and is harder to upgrade. Tablets use touch screens instead of keyboards and are light, have long battery life and are ideal for reading, browsing and watching media. Smartphones combine telephone, internet, camera and applications in a pocket-sized device, while phablets are large smartphones with screens between a phone and a tablet.

Mobile devices connect to the internet using Wi-Fi or mobile networks such as 4G and 5G, which allows people to work remotely, communicate instantly and use location services through GPS. The disadvantages are smaller screens that make detailed work difficult, touch keyboards that are slower for typing long documents, lower processing power than desktops, security risks if the device is lost, and the need to recharge frequently. Exam questions often ask you to recommend a type of computer for a specific person, so always link your answer to the user's needs.

  • Desktop: powerful, upgradable, cheaper per unit of power, not portable.
  • Laptop: portable with a full keyboard, limited battery, less upgradable.
  • Tablet: light, long battery, touch screen, poor for long typing.
  • Smartphone: extremely portable, always connected, small screen, limited processing.
06

Analogue and Digital Data

Computers can only process digital data, which is data made up of discrete values, stored as binary digits (0s and 1s). In contrast, analogue data is continuously variable data, such as temperature, sound waves, light intensity or pressure in the real world. A thermometer reading can take any value between two points, whereas a digital value can only be one of a fixed set of steps. Because sensors measure the physical world, their output is usually analogue and must be converted before a computer can use it.

An analogue-to-digital converter (ADC) converts analogue signals from sensors or microphones into digital data that a computer can store and process. A digital-to-analogue converter (DAC) does the reverse, converting digital data from the computer into an analogue signal that can drive devices such as speakers or motors. For example, when you record your voice, the microphone produces an analogue electrical signal, the ADC samples it thousands of times a second and converts each sample into a binary number, and when you play it back the DAC rebuilds an analogue wave for the speakers.

Key fact:ADC: analogue to digital (sensor to computer). DAC: digital to analogue (computer to speaker or motor).
07

Emerging Technologies

Artificial intelligence (AI) is the ability of a computer system to simulate intelligent human behaviour, such as learning, reasoning, recognising speech and making decisions. Examples include voice assistants, facial recognition, chatbots, recommendation systems on shopping and streaming sites, and self-driving cars. AI can work continuously, process huge amounts of data quickly and remove humans from dangerous tasks. However, it can lead to job losses, it may make biased decisions if trained on biased data, and people can become over-reliant on it or lose skills.

Extended reality (XR) is the umbrella term for technologies that merge the real and virtual worlds. Virtual reality (VR) places the user in a completely computer-generated environment using a headset, often with gloves or controllers, and is used for flight simulators, training surgeons, games, virtual tours of buildings and treating phobias. Augmented reality (AR) overlays digital information on a view of the real world, usually through a smartphone camera or smart glasses, for example showing furniture in your room before you buy it, navigation arrows on a street, or information about exhibits in a museum.

The impact of these technologies is significant. VR allows training in realistic but safe environments, so trainee pilots or firefighters can make mistakes without real danger. AR helps engineers see hidden pipes or wiring and helps shoppers visualise products. Disadvantages include the high cost of headsets, motion sickness and eye strain from long use, and a reduction in face-to-face social contact. In the exam, always state a specific use and then explain the benefit, rather than giving a vague answer such as saying it is more fun.

Key fact:VR = fully virtual world. AR = digital content added on top of the real world.

Worked Examples

Recommending a computer for a user

A travelling sales representative needs to create presentations, reply to emails and show product videos to clients in their offices. Recommend whether she should use a desktop, a laptop or a smartphone, and justify your answer.

  1. Identify her needs: portability because she travels, a full keyboard for writing emails and presentations, and a screen large enough to show videos to clients.
  2. Reject the desktop: it is not portable and needs mains power, so it cannot be taken to clients' offices.
  3. Consider the smartphone: very portable, but the small screen is poor for showing videos to a group and the touch keyboard is slow for creating presentations.
  4. Choose the laptop: it is portable, has a full keyboard and a reasonable screen, can run presentation software and has a battery for use away from power sockets.
A laptop is the best choice because it combines portability and battery power with a full keyboard and a screen large enough for creating presentations and showing videos to clients.

Comparing RAM and ROM (model answer)

Describe two differences between RAM and ROM. (4 marks)

  1. Difference one, volatility: RAM is volatile, so its contents are lost when the computer is switched off, whereas ROM is non-volatile and keeps its contents without power.
  2. Difference two, read and write: RAM can be read from and written to, whereas ROM can normally only be read from.
  3. Alternative difference, contents: RAM stores the programs and data currently in use, whereas ROM stores the BIOS or start-up instructions.
  4. Make sure each difference compares both types, as the mark scheme awards one mark for each side of the comparison.
RAM is volatile but ROM is non-volatile; RAM can be written to but ROM is read only (also accept: RAM holds current programs and data while ROM holds the start-up instructions; RAM is usually larger than ROM).

Choosing a user interface

A network technician manages hundreds of servers and wants to delete old log files on all of them quickly. Explain why a command line interface may be more suitable than a GUI for this task.

  1. A CLI lets the technician type a single command that can act on many files at once, or be written into a script that runs on every server.
  2. A CLI uses less memory and processing power, which matters on servers that must dedicate resources to other work.
  3. The technician is an expert, so remembering the command syntax is not a problem.
  4. In a GUI, the technician would have to click through folders and select files manually, which is slow and error prone for hundreds of servers.
The CLI is more suitable because an expert can type or script precise commands that affect many files at once, it uses fewer resources, and it is much faster than repeated clicking in a GUI.

Common Mistakes & Exam Tips

Common mistakes

  • Saying RAM stores files permanently. RAM is volatile and temporary; files are stored permanently on backing storage.
  • Calling the whole computer case the CPU. The CPU is the processor chip on the motherboard, not the box itself.
  • Listing the operating system as application software. The OS is system software; application software performs user tasks.
  • Writing 'a GUI is easier' without explaining why. Say it uses icons and menus so users do not need to remember commands.
  • Confusing AR and VR. VR replaces the real world with a virtual one; AR adds digital content on top of the real world.
  • Giving vague advantages such as 'faster' or 'better' without stating what is faster or better and for whom.

Exam tips

  • When comparing two items, write both sides in the same sentence using words like 'whereas' or 'but', for example 'RAM is volatile whereas ROM is non-volatile'.
  • For 'recommend a device' questions, identify the user's needs first and link each feature of your chosen device to one of those needs.
  • Learn at least three examples each of application software and system software; one-word examples often score marks in part (a) questions.
  • If a question says 'describe', give a feature plus detail; if it says 'explain', give a reason using 'because' or 'so that'.
  • Count the marks: a 4-mark 'advantages and disadvantages' question usually needs two of each, not four advantages.
  • Use correct technical vocabulary such as volatile, non-volatile, peripheral and device driver; examiners reward precise terms.

Practice Questions

[3 marks]

1. Define the term hardware and give two examples of internal hardware.

Model answerHardware is the physical components of a computer system (1). Examples: CPU, RAM, ROM, motherboard, graphics card, sound card, NIC, internal hard disk (any two, 1 mark each).
[2 marks]

2. State two examples of system software.

Model answerAny two from: operating system, compiler, interpreter, linker, device driver, utility such as anti-virus or defragmenter (1 mark each).
[2 marks]

3. Explain what is meant by volatile memory and name a type of volatile memory.

Model answerVolatile memory loses its contents when the power is turned off (1). RAM is volatile (1).
[2 marks]

4. Describe the purpose of ROM in a computer.

Model answerROM stores the start-up instructions/BIOS (1) needed to load the operating system when the computer is switched on (1); its contents are not lost when power is off so they are always available (1).
[4 marks]

5. Describe two functions of an operating system.

Model answerAny two described: manages memory by allocating RAM to programs; manages files and folders on storage; controls input and output devices using drivers; provides a user interface; handles security such as user accounts and passwords; handles errors and interrupts; allows multitasking (2 marks each: function plus detail).
[4 marks]

6. Give two advantages and two disadvantages of a command line interface compared with a graphical user interface.

Model answerAdvantages: uses less memory/processing power; faster for expert users; allows direct control and scripting of tasks. Disadvantages: user must learn and remember commands; commands must be typed exactly so errors are common; not intuitive for beginners (1 mark each, max 2 each side).
[3 marks]

7. Explain why an analogue-to-digital converter is needed when a temperature sensor is connected to a computer.

Model answerThe sensor produces analogue data which varies continuously (1). The computer can only process digital/binary data (1), so the ADC converts the analogue signal into digital values the computer can use (1).
[4 marks]

8. Compare the use of a tablet computer and a desktop computer for a student writing a 3,000-word essay.

Model answerDesktop has a full-size physical keyboard so typing is faster and more comfortable (1); larger screen makes editing easier (1); tablet is portable so can be used anywhere (1) but its touch keyboard is slower and smaller screen harder to work on (1); tablet has battery so no need for mains power (1). Conclusion that desktop (or laptop) is better for long typing (1). Max 4.
[3 marks]

9. Describe what is meant by virtual reality and give one use in education or training.

Model answerVR is a computer-generated, fully immersive 3D environment (1) experienced through a headset and often gloves/controllers (1). Use: e.g. flight simulator for pilots, surgical training, virtual field trips (1).
[6 marks]

10. Discuss the advantages and disadvantages of artificial intelligence in everyday life.

Model answerAdvantages: can work 24/7 without tiring; processes large amounts of data quickly; can make accurate predictions and recommendations; can replace humans in dangerous jobs; voice assistants help disabled users. Disadvantages: job losses in some industries; expensive to develop; decisions may be biased if trained on biased data; privacy concerns from data collection; people may become over-reliant and lose skills. Balanced discussion with a conclusion for full marks (1 mark per valid point, max 6).
[2 marks]

11. State the difference between a compiler and a linker.

Model answerA compiler translates a high-level language program into machine code (1); a linker combines separately compiled modules/object files into a single executable program (1).

13

Quick Recap

  1. Hardware is the physical parts of a computer; software is the programs that control it.
  2. Application software carries out user tasks, while system software manages the hardware and runs applications.
  3. The CPU processes instructions, RAM temporarily holds data in use, and ROM stores start-up instructions permanently.
  4. Backing storage is non-volatile, large and slower than RAM, and keeps files permanently.
  5. User interfaces include CLI, GUI, dialogue-based and gesture-based, each with clear advantages and drawbacks.
  6. Desktops are powerful and upgradable, while mobile devices trade power and screen size for portability.
  7. Sensors produce analogue data that must be converted to digital data by an ADC before processing.
  8. AI, VR and AR are emerging technologies with major benefits for training and daily life, but with costs and risks.
