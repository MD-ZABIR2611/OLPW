Data Structures & File Handling

CORE
SECTION 01 — CHAPTER OVERVIEW

Organizing Data

Programs need efficient ways to store and manipulate large amounts of data. This chapter covers data structures like arrays, stacks, and queues, as well as the algorithms used to search and sort them. It also covers reading from and writing to text files.

SECTION 03 — CORE THEORY

Structures & Algorithms

An Array is a collection of elements of the same data type accessed by an index. A Record holds multiple fields of different data types for a single entity (e.g., a Student record with Name, Age, and Grade).

Stacks vs Queues

Stack (LIFO): Last In, First Out. Items are added (pushed) and removed (popped) from the same end. Used for undo features.

Queue (FIFO): First In, First Out. Items are added (enqueued) at the back and removed (dequeued) from the front. Used for print queues.

File Handling

Files allow data to be stored permanently. To use a file, a program must OPEN it (in Read, Write, or Append mode), process the data, and then CLOSE it. Closing the file saves changes and frees up memory.

SECTION 04 — KEY DEFINITIONS

Examination Definitions

DATA STRUCTURE: A format for storing and organizing data so it can be used efficiently.

LINEAR SEARCH: A search algorithm that checks every element in an array in order until the target is found.

BUBBLE SORT: A sorting algorithm that repeatedly steps through a list, compares adjacent pairs, and swaps them if they are in the wrong order.

SECTION 06 — TRACE TABLES & LOGIC

Tracing a Bubble Sort

Below is the trace table for the first pass of a Bubble Sort on an array of 3 numbers: [5, 2, 8]. It compares adjacent elements and swaps them if the left is greater than the right.

FOR i = 0 TO 1 IF Array[i] > Array[i+1] THEN Temp = Array[i] Array[i] = Array[i+1] Array[i+1] = Temp ENDIF NEXT i
PASS (i) Array[i] Array[i+1] Swap? Array State
052YES[2, 5, 8]
158NO[2, 5, 8]

Final sorted array: [2, 5, 8]

SECTION 07 — EXAM TECHNIQUE

Trace Table Accuracy

When tracing arrays, always update the entire array state in the table after a swap. Do not just track the loop counter. Examiners look for the state of all variables at each iteration boundary.

SECTION 08 — COMMON MISTAKES

Avoid These Errors

Mistake: "Index out of bounds" errors.

Correction: If an array has 5 elements, its indices are 0 to 4. A loop FOR i = 0 TO 5 will cause an error. Use TO 4.

SECTION 09 — QUICK REVISION

Fast Facts

  • Stack = LIFO. Queue = FIFO.
  • Arrays use zero-based indexing (first element is 0).
  • Linear search works on unsorted lists; Binary search requires a sorted list.
  • Always CLOSE files after reading/writing to prevent data corruption.
SECTION 10 — EXAM QUESTIONS

Test Your Knowledge

Question 1 (Standard)

Explain the difference between a Stack and a Queue, giving one real-world use case for each.

4 marks: A stack uses LIFO (Last In First Out), meaning the last item added is the first removed. Used for undo history. A queue uses FIFO (First In First Out), meaning the first item added is the first removed. Used for a printer queue.
