Key Concepts

01

Histograms have no gaps between bars.

02

Frequency density = frequency ÷ class width.

03

The area of each bar is proportional to frequency.

04

Frequency polygons join midpoints of class tops.

02

Key Terms

TermExam definition
Frequency densityFrequency divided by class width.
HistogramA chart for continuous data where area represents frequency.
Frequency polygonA line graph joining the midpoints of class intervals.
03

Exam Tip

Examiner says

With unequal class widths, always plot frequency density, not frequency.
