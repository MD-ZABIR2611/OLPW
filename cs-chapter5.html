Operating Systems & Software

CORE
SECTION 01 — CHAPTER OVERVIEW

Managing the Machine

Without an Operating System (OS), a computer is just a pile of useless metal and silicon. This chapter explores the vital role of system software in managing hardware resources, providing a user interface, and running applications.

SECTION 02 — LEARNING OBJECTIVES

Chapter Goals

  • Distinguish between system software and application software.
  • State the functions of an Operating System.
  • Compare GUI and CLI interfaces.
  • Explain the purpose of utility software (defragmentation, compression).
SECTION 03 — CORE THEORY

Software Hierarchy

System Software runs the hardware (OS, drivers, utilities). Application Software allows the user to perform specific tasks (Word, Chrome, Games).

OS Core Functions

1. Memory Management: Allocates RAM to programs. Uses Virtual Memory if RAM is full.

2. File Management: Creates folders, moves files, manages storage.

3. Peripheral Management: Uses device drivers to communicate with printers, mice, etc.

4. Multitasking: Allows multiple applications to run seemingly simultaneously by time-slicing the CPU.

User Interfaces

GUI (Graphical User Interface): Uses windows, icons, menus, pointers (WIMP). Easy for beginners, but consumes heavy RAM/CPU.

CLI (Command Line Interface): Text-based. Requires typing exact commands. Hard to learn, but lightweight, fast, and scriptable for automation.

SECTION 04 — KEY DEFINITIONS

Examination Definitions

OPERATING SYSTEM: System software that manages computer hardware and software resources and provides common services for computer programs.

DEVICE DRIVER: A computer program that operates or controls a particular type of device that is attached to a computer.

DEFRAGMENTATION: The process of locating noncontiguous fragments of data and reorganizing them into fewer fragments on a magnetic hard drive.

SECTION 06 — EXAM TECHNIQUE

Explain vs Describe

If asked to "Explain" why defragmentation is needed, do not just say "it puts files together". Say "it reorganizes fragmented files into contiguous blocks, which reduces the read/write head movement, thereby decreasing file access times."

SECTION 07 — COMMON MISTAKES

Avoid These Errors

Mistake: Defragmenting an SSD (Solid State Drive).

Correction: Defragging is only for magnetic HDDs. SSDs use flash memory and have no moving parts. Defragging an SSD wears it out unnecessarily and provides no speed benefit.

SECTION 08 — QUICK REVISION

Fast Facts

  • OS manages Memory, Files, Peripherals, and Processes.
  • GUI = WIMP (Windows, Icons, Menus, Pointer).
  • CLI is text-based and requires less processing power.
  • Compression utilities reduce file size for storage/transmission.
SECTION 09 — EXAM QUESTIONS

Test Your Knowledge

Question 1 (Standard)

A user is running a graphics-intensive game and simultaneously downloading a large file. Explain how the Operating System manages the CPU to allow both to happen.

2 marks: The OS uses multitasking/time-slicing. It allocates small, rapid time slices of CPU processing power to each application in turn. This happens so fast that the user perceives both tasks running simultaneously.
