Core Computing Formulas

  • Image File Size = Resolution $\times$ Colour Depth (bits)
  • Sound File Size = Sample Rate $\times$ Sample Resolution $\times$ Duration
  • File Size (Bytes) = Total Bits / 8

Logic Gates & Truth Tables

  • AND: Output is 1 only if BOTH inputs are 1.
  • OR: Output is 1 if AT LEAST ONE input is 1.
  • NOT: Inverts the input (1 becomes 0, 0 becomes 1).
  • XOR: Output is 1 if inputs are DIFFERENT.

Algorithm Complexity

  • Linear Search: O(n). Checks every item.
  • Binary Search: O(log n). Requires sorted list. Halves search area.
  • Bubble Sort: Swaps adjacent elements. Inefficient for large lists.
  • Stack = LIFO (Last In, First Out). Queue = FIFO (First In, First Out).

Exam Command Words

  • STATE: Give a short fact.
  • DESCRIBE: Say what happens/trends.
  • EXPLAIN: Give reasons/mechanisms (use "because").
  • COMPARE: Give similarities and differences.
  • CALCULATE: Show formula, working, and units.
