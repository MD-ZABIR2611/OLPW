Quadratic Functions

01

Overview

A quadratic function has the form f(x) = ax² + bx + c with a ≠ 0, and its graph is a symmetrical curve called a parabola. Quadratics appear everywhere in Additional Mathematics: in maximum and minimum problems, in the intersection of lines and curves, in inequalities and in later calculus questions. This chapter builds the key techniques of completing the square and using the discriminant b² − 4ac, which let you find turning points and decide how many roots an equation has without solving it. These skills are tested directly in almost every paper and support many longer questions.

By the end of this chapter you should be able to:

  • Solve quadratic equations by factorising, completing the square and the quadratic formula.
  • Write a quadratic in the completed square form a(x + p)² + q and use it to find the vertex and the maximum or minimum value.
  • Sketch the graph of a quadratic function showing intercepts, turning point and line of symmetry.
  • Use the discriminant b² − 4ac to determine the nature of the roots of a quadratic equation.
  • Solve quadratic inequalities and represent the solution set correctly.
  • Decide whether a straight line intersects, touches or misses a curve by forming a quadratic and using its discriminant.
02

Solving Quadratic Equations

There are three standard ways to solve ax² + bx + c = 0. Factorising is fastest when it works: for x² − x − 12 = 0, find two numbers that multiply to −12 and add to −1, namely −4 and 3, giving (x − 4)(x + 3) = 0 and x = 4 or x = −3. When a ≠ 1, use the 'ac method': for 2x² + 5x − 3 = 0, look for numbers that multiply to 2 × (−3) = −6 and add to 5, namely 6 and −1, then split the middle term: 2x² + 6x − x − 3 = 2x(x + 3) − (x + 3) = (2x − 1)(x + 3).

The quadratic formula x = [−b ± √(b² − 4ac)]/(2a) works for every quadratic, so use it whenever factorising is not obvious or when answers are required to a number of significant figures or in surd form. Write down the values of a, b and c first, including their signs, and substitute carefully in brackets. For 3x² − 7x + 1 = 0, a = 3, b = −7 and c = 1, so x = [7 ± √(49 − 12)]/6 = (7 ± √37)/6, giving x ≈ 2.18 or x ≈ 0.153.

Before solving, always rearrange the equation so one side is zero. An equation such as x(x + 2) = 15 must become x² + 2x − 15 = 0 before factorising; it is a serious error to set each factor equal to 15. Similarly, never divide both sides by x, because you would lose the solution x = 0. For x² = 5x, write x² − 5x = 0, so x(x − 5) = 0, giving x = 0 or x = 5.

Key fact:Quadratic formula: x = [−b ± √(b² − 4ac)] / (2a).
03

Completing the Square

Completing the square rewrites x² + bx + c in the form (x + p)² + q. The key identity is x² + bx = (x + b/2)² − (b/2)². For x² + 8x + 3, half of 8 is 4, so x² + 8x = (x + 4)² − 16, and therefore x² + 8x + 3 = (x + 4)² − 13. Expanding the answer to check is quick and worthwhile: (x + 4)² − 13 = x² + 8x + 16 − 13 = x² + 8x + 3.

When the coefficient of x² is not 1, take it out as a factor from the x² and x terms only. For 2x² − 12x + 7, write 2(x² − 6x) + 7, then complete the square inside the bracket: x² − 6x = (x − 3)² − 9. So the expression is 2[(x − 3)² − 9] + 7 = 2(x − 3)² − 18 + 7 = 2(x − 3)² − 11. The common error is forgetting to multiply the −9 by 2 when removing the square bracket.

For a negative x² coefficient, such as 5 + 4x − x², factor out −1: −(x² − 4x) + 5 = −[(x − 2)² − 4] + 5 = −(x − 2)² + 9, which is usually written 9 − (x − 2)². Exam questions frequently ask for the form a − (x − b)² or a(x + b)² + c, so match the requested format exactly and state the values of the constants clearly.

  • x² + bx + c = (x + b/2)² − (b/2)² + c.
  • ax² + bx + c: factor a out of the first two terms, complete the square, then multiply back.
  • Always expand your answer mentally to check it matches the original.
04

Turning Points, Symmetry and Range

The completed square form a(x + p)² + q shows the turning point, also called the vertex, immediately. Because (x + p)² is never negative, it is smallest (zero) when x = −p. If a > 0, the parabola is U-shaped and the minimum point is (−p, q). If a < 0, the parabola is an inverted U and (−p, q) is a maximum point. For y = 2(x − 3)² − 11, the minimum point is (3, −11) and the minimum value of y is −11.

The line of symmetry passes vertically through the vertex, so its equation is x = −p, which is the same as x = −b/(2a). This is useful as a check: for 2x² − 12x + 7, −b/(2a) = 12/4 = 3, agreeing with the completed square form. The roots of the equation, when they exist, are placed symmetrically either side of this line, so their average always equals the x-coordinate of the vertex.

The range of a quadratic function over all real numbers follows from the vertex. For f(x) = 2(x − 3)² − 11, the range is f(x) ≥ −11; for g(x) = 9 − (x − 2)², the range is g(x) ≤ 9. If the domain is restricted, check whether the vertex lies inside it. If it does, the vertex value is one end of the range; if not, evaluate the function at the ends of the domain instead.

Key fact:For y = a(x + p)² + q, the vertex is (−p, q): a minimum if a > 0, a maximum if a < 0.
05

Sketching Quadratic Graphs

A good sketch of a quadratic shows four features: the correct shape (U for a > 0, inverted U for a < 0), the y-intercept, any x-intercepts and the vertex. The y-intercept is found by putting x = 0, so it is always (0, c). The x-intercepts are the roots of ax² + bx + c = 0. The vertex comes from completing the square or from x = −b/(2a). Label each point with its coordinates; a sketch without labelled points rarely scores full marks.

Take y = x² − 2x − 8 as an example. It factorises as (x − 4)(x + 2), so it crosses the x-axis at (4, 0) and (−2, 0). The y-intercept is (0, −8). The line of symmetry is x = 1, halfway between the roots, and the minimum value is y = 1 − 2 − 8 = −9, so the vertex is (1, −9). The curve is a U shape passing through these four points.

If a quadratic has no real roots, the graph does not cross the x-axis at all. For y = x² + 4x + 7 = (x + 2)² + 3, the minimum point is (−2, 3), above the axis, so the whole curve lies above the x-axis. This links directly to the discriminant: here b² − 4ac = 16 − 28 = −12, which is negative, confirming there are no real roots and that the expression is always positive.

06

The Discriminant and the Nature of Roots

The expression b² − 4ac, which sits under the square root in the quadratic formula, is called the discriminant. Its sign tells you how many real roots the equation ax² + bx + c = 0 has without solving it. If b² − 4ac > 0, the square root is a positive real number and the formula gives two distinct real roots. If b² − 4ac = 0, the ± part vanishes and there is exactly one repeated root, meaning the graph touches the x-axis at its vertex. If b² − 4ac < 0, the square root is not real and there are no real roots.

Many exam questions include an unknown constant k and ask for the values of k that produce a particular type of root. The method is always the same: identify a, b and c in terms of k, form the discriminant, apply the appropriate condition, and solve the resulting equation or inequality in k. For x² + kx + 9 = 0 to have equal roots, you need k² − 4(1)(9) = 0, so k² = 36 and k = ±6.

The phrase 'real roots' includes both the distinct and the equal case, so the condition is b² − 4ac ≥ 0. Watch out for questions where the coefficient of x² contains k: if it could be zero, the equation would no longer be quadratic, and you may need to exclude that value. Also note that a quadratic that is 'always positive' for all x needs a > 0 and b² − 4ac < 0.

  • b² − 4ac > 0: two distinct real roots; the curve crosses the x-axis twice.
  • b² − 4ac = 0: two equal (repeated) roots; the curve touches the x-axis.
  • b² − 4ac < 0: no real roots; the curve does not meet the x-axis.
  • b² − 4ac ≥ 0: real roots (distinct or equal).
07

Quadratic Inequalities

To solve a quadratic inequality, first rearrange so that one side is zero, then find the critical values by solving the corresponding equation. Next, sketch the parabola through these roots and read off where the graph is above the x-axis (positive) or below it (negative). For 2x² − 5x − 3 > 0, factorising gives (2x + 1)(x − 3) > 0 with critical values x = −½ and x = 3. The graph is a U shape, which is above the axis outside the roots, so the solution is x < −½ or x > 3.

For a 'less than' inequality with a positive x² coefficient, the solution lies between the roots. For x² − x − 12 ≤ 0, the roots are x = −3 and x = 4, and the U-shaped graph is on or below the axis between them, so −3 ≤ x ≤ 4. Notice that the inequality sign ≤ keeps the end points, while < would exclude them. Writing a 'between' answer as a single combined inequality is standard, but an 'outside' answer must be written as two separate inequalities joined by 'or'.

Never try to solve a quadratic inequality by treating it like an equation and writing x > 3 and x > −½; the sign of a product depends on the signs of both factors, which is why the sketch is so important. If the x² coefficient is negative, you can multiply through by −1, remembering to reverse the inequality sign, so that you always work with a U-shaped graph.

Key fact:For (x − α)(x − β) with α < β: > 0 gives x < α or x > β; < 0 gives α < x < β.
08

Intersection of a Line and a Curve

To find where a straight line meets a curve, solve their equations simultaneously. Usually you rearrange the linear equation to make y (or x) the subject and substitute into the curve's equation, producing a quadratic. For y = x + 3 and y = x² − 3x + 6, substitution gives x² − 3x + 6 = x + 3, so x² − 4x + 3 = 0 and (x − 1)(x − 3) = 0. Substituting back into the line gives the points (1, 4) and (3, 6). Always use the linear equation for the y-values, since it is simpler and less error-prone.

The discriminant of this resulting quadratic reveals the geometric relationship between the line and the curve. Two distinct real roots mean the line crosses the curve at two points; a repeated root means the line is a tangent, touching the curve at exactly one point; no real roots mean the line misses the curve completely. This gives a powerful method for tangent questions without any calculus.

For example, to find the values of k for which y = kx − 3 is a tangent to y = x² + 1, write x² + 1 = kx − 3, so x² − kx + 4 = 0. For a tangent, the discriminant is zero: k² − 16 = 0, so k = 4 or k = −4. Substituting k = 4 gives x² − 4x + 4 = 0, so x = 2 and the point of contact is (2, 5); k = −4 gives x = −2 and the point (−2, 5).

  • Substitute the line into the curve to form a single quadratic equal to zero.
  • Two intersections: b² − 4ac > 0. Tangent: b² − 4ac = 0. No intersection: b² − 4ac < 0.
  • Find y-coordinates by substituting into the equation of the line.

Key Terms

TermExam definition
Quadratic functionA function of the form f(x) = ax² + bx + c where a, b and c are constants and a ≠ 0.
ParabolaThe symmetrical U-shaped or inverted U-shaped curve that is the graph of a quadratic function.
RootA value of x that satisfies the equation f(x) = 0; graphically, an x-coordinate where the curve meets the x-axis.
Completing the squareRewriting ax² + bx + c in the form a(x + p)² + q to reveal the vertex.
Vertex (turning point)The maximum or minimum point of a parabola, located on its line of symmetry.
Line of symmetryThe vertical line x = −b/(2a) through the vertex, about which the parabola is symmetrical.
DiscriminantThe value b² − 4ac, whose sign determines the number of real roots of ax² + bx + c = 0.
Repeated (equal) rootsThe case b² − 4ac = 0, where the equation has one root counted twice and the curve touches the x-axis.
Critical valuesThe roots of the equation associated with an inequality, which mark the boundaries of the solution set.
TangentA straight line that touches a curve at exactly one point without crossing it at that point.
Quadratic inequalityAn inequality involving a quadratic expression, such as x² − x − 12 ≤ 0.
CoefficientThe constant number multiplying a power of x in an expression, such as 3 in 3x².

Worked Examples

Completing the square to find a minimum

Express 2x² − 12x + 7 in the form a(x + b)² + c. Hence state the minimum value of 2x² − 12x + 7 and the value of x at which it occurs.

  1. Take out the factor 2 from the first two terms: 2x² − 12x + 7 = 2(x² − 6x) + 7.
  2. Complete the square inside: x² − 6x = (x − 3)² − 9.
  3. Substitute: 2[(x − 3)² − 9] + 7 = 2(x − 3)² − 18 + 7 = 2(x − 3)² − 11.
  4. So a = 2, b = −3 and c = −11. Since 2(x − 3)² ≥ 0, the expression is least when x − 3 = 0.
  5. Check by expanding: 2(x² − 6x + 9) − 11 = 2x² − 12x + 18 − 11 = 2x² − 12x + 7. Correct.
2x² − 12x + 7 = 2(x − 3)² − 11; minimum value −11 when x = 3.

Values of k for real roots

Find the set of values of k for which the equation kx² + 4x + (k − 3) = 0 has real roots, where k ≠ 0.

  1. Identify a = k, b = 4, c = k − 3. For real roots, b² − 4ac ≥ 0.
  2. Substitute: 16 − 4k(k − 3) ≥ 0, which gives 16 − 4k² + 12k ≥ 0.
  3. Divide by −4 and reverse the inequality: k² − 3k − 4 ≤ 0.
  4. Factorise: (k − 4)(k + 1) ≤ 0, with critical values k = −1 and k = 4.
  5. A U-shaped graph in k is on or below the axis between the roots, so −1 ≤ k ≤ 4. Exclude k = 0 because the equation must be quadratic.
−1 ≤ k ≤ 4, k ≠ 0.

A line that does not meet a curve

Find the set of values of m for which the line y = mx + 1 does not meet the curve y = x² − 2x + 5.

  1. Equate: x² − 2x + 5 = mx + 1, so x² − (2 + m)x + 4 = 0.
  2. For no intersection, the discriminant is negative: (2 + m)² − 4(1)(4) < 0.
  3. So (2 + m)² < 16, which means −4 < 2 + m < 4.
  4. Subtract 2 throughout: −6 < m < 2.
  5. Check with m = 0: x² − 2x + 4 = 0 has discriminant 4 − 16 = −12 < 0, so no intersection, consistent with the answer.
−6 < m < 2.

Common Mistakes & Exam Tips

Common mistakes

  • Forgetting to multiply the constant by a when completing the square with a ≠ 1: 2[(x − 3)² − 9] + 7 gives −18 + 7, not −9 + 7.
  • Writing the vertex of y = (x + 4)² − 13 as (4, −13). The x-coordinate makes the bracket zero, so the vertex is (−4, −13).
  • Solving a quadratic inequality by treating each factor separately, such as writing x > 3 and x > −½. Always sketch the parabola and read off the correct regions.
  • Using b² − 4ac > 0 when the question says 'real roots'. Real roots includes equal roots, so the condition is b² − 4ac ≥ 0.
  • Dividing by x or by a factor containing x, which loses roots. Rearrange to zero and factorise instead.
  • Writing an 'outside' solution as a single inequality such as 3 < x < −½. This is impossible; write x < −½ or x > 3.

Exam tips

  • Before using the discriminant, rearrange the equation into the form ax² + bx + c = 0 and write down a, b and c explicitly.
  • In 'line and curve' questions, state which condition you are using, for example 'for a tangent, b² − 4ac = 0', to secure the method mark.
  • When the question says 'hence', use your completed square form directly to write down the vertex or range rather than starting again.
  • Always show a quick sketch for quadratic inequalities; it takes seconds and prevents sign errors.
  • If an answer must be given in surd form, keep √ values exact and simplify, e.g. (−12 ± √88)/4 = (−6 ± √22)/2.
  • Check answers to tangent questions by substituting the value of k back and confirming you get a perfect square.

Quick Recap

  1. Quadratic equations can be solved by factorising, completing the square or the quadratic formula; always rearrange to zero first.
  2. Completing the square gives a(x + p)² + q, from which the vertex (−p, q) and the maximum or minimum value can be read.
  3. The line of symmetry of y = ax² + bx + c is x = −b/(2a), and the y-intercept is (0, c).
  4. The discriminant b² − 4ac is positive for two distinct roots, zero for equal roots and negative for no real roots.
  5. Solve quadratic inequalities by finding critical values and sketching the parabola to see where it is above or below the axis.
  6. Substituting a line into a curve gives a quadratic whose discriminant shows whether the line crosses, touches or misses the curve.
  7. An expression ax² + bx + c is positive for all x when a > 0 and b² − 4ac < 0.
