SECTION 03 — CORE THEORY

Debugging & Testing

Syntax Errors: Mistakes in the grammar of the code (e.g., missing a bracket). The program will not run.

Logic Errors: The program runs but produces the wrong output (e.g., using `+` instead of `-`).

Runtime Errors: The program crashes during execution (e.g., dividing by zero).

Test Data Types

To ensure a program is robust, test it with:

1. Normal data: Typical, expected inputs.

2. Boundary data: The exact limits of acceptance.

3. Erroneous data: Data that should be rejected to test validation.

SECTION 04 — KEY DEFINITIONS

Examination Definitions

DEBUGGING: The process of finding and fixing errors (bugs) in program code.

DRY RUN: Manually tracing through code on paper to determine outputs and find logic errors.

SECTION 06 — TRACE TABLES & LOGIC

Debugging Trace Table

The code below intends to find the maximum value in an array [3, 7, 2]. However, there is a logic error.

Max = 0 FOR i = 0 TO 2 IF Array[i] > Max THEN Max = Array[i] ENDIF NEXT i OUTPUT Max
i Array[i] Max Array[i] > Max?
033YES
177YES
227NO

The code outputs 7. This works for positive numbers, but what if the array only contained negative numbers? E.g., [-5, -2, -9]. The output would be 0, which is incorrect. Fix: Initialize Max = Array[0].

SECTION 07 — EXAM TECHNIQUE

Command Words

State: Give a fact without explanation.

Describe: Give a detailed account of what happens.

Explain: Give reasons or mechanisms (why/how).

Justify: Support a choice with reasons.

SECTION 08 — COMMON MISTAKES

Avoid These Errors

Mistake: Not reading the question carefully.

Correction: Circle the command word. If it says "Explain", do not just "State". If it says "Write pseudocode", do not write Python.

SECTION 09 — QUICK REVISION

Fast Facts

  • Syntax = Grammar error. Logic = Wrong output. Runtime = Crash.
  • Always test Boundary data (e.g., if range is 1-10, test 0, 1, 10, 11).
  • Trace tables are your best tool for finding logic errors.
SECTION 10 — EXAM QUESTIONS

Test Your Knowledge

Question 1 (Challenge)

A program asks a user to input their age (an integer between 1 and 100). State the test data you would use to fully test this input, categorizing them as Normal, Boundary, and Erroneous.

4 marks:

Normal: 50 (typical input).

Boundary: 1, 100 (edges of valid range), 0, 101 (edges of invalid range).

Erroneous: -5 (out of range), "Thirty" (wrong data type).
