Databases & SQL

CORE
SECTION 01 — CHAPTER OVERVIEW

Relational Databases

Databases are designed to efficiently store, search, and manage large volumes of structured data. This chapter covers the structure of relational databases and how to interact with them using SQL (Structured Query Language).

SECTION 02 — LEARNING OBJECTIVES

Chapter Goals

  • Explain the purpose of a foreign key.
  • Distinguish between validation and verification.
  • Write basic SQL queries using SELECT, FROM, WHERE, and ORDER BY.
SECTION 03 — CORE THEORY

Database Structure

A database is a collection of Tables. A table represents one entity (e.g., Students). Each table has Fields (columns representing attributes like Name or Age) and Records (rows representing individual items).

Keys

Primary Key: A field that uniquely identifies each record. (e.g., StudentID). It cannot be empty (null) or duplicated.

Foreign Key: A field in one table that references the Primary Key of another table. It links tables together in a relational database.

Validation vs Verification

Validation is an automated check that data is reasonable and in the correct format before processing (e.g., Range check: Age must be 0-120).

Verification is ensuring data is exactly what was intended, usually done by humans (e.g., double-checking a password, or a visual check of a scanned document).

SECTION 04 — KEY DEFINITIONS

Examination Definitions

DBMS: Database Management System. Software that creates and manages databases.

SQL: Structured Query Language. A standard language for accessing and manipulating databases.

QUERY: A request for data from a database.

SECTION 06 — SQL QUERIES

Writing SQL

SQL is used to extract data from a database. The most common command is SELECT.

-- Select all data from the Students table SELECT * FROM Students; -- Select names of students older than 15, sorted alphabetically SELECT Name FROM Students WHERE Age > 15 ORDER BY Name ASC; -- Insert a new student record INSERT INTO Students (StudentID, Name, Age) VALUES (104, 'Alice', 16);

SQL can also update data using UPDATE or delete records using DELETE.

SECTION 07 — EXAM TECHNIQUE

SQL Syntax Rules

Always end SQL statements with a semicolon ;. String values in WHERE clauses must be enclosed in single quotes ' '. (e.g., WHERE Name = 'John'). Field names with spaces should be avoided or enclosed in brackets.

SECTION 08 — COMMON MISTAKES

Avoid These Errors

Mistake: Using WHERE to sort data.

Correction: WHERE filters rows. ORDER BY sorts the output. They serve different purposes.

Mistake: Confusing Primary Keys and Foreign Keys.

Correction: PK is unique in its own table. FK is a reference to a PK in another table; it does not have to be unique in its current table.

SECTION 09 — QUICK REVISION

Fast Facts

  • Table = Entity. Field = Attribute. Record = Row.
  • Primary Key = Unique identifier.
  • Foreign Key = Links to Primary Key of another table.
  • Validation = Automated check. Verification = Human check.
