Tabulation and Classification

How to organise raw data into well-constructed frequency tables and two-way tables, and how to work with class limits, class boundaries, class widths and mid-interval values.

01

Overview

Once data have been collected they must be organised before anyone can make sense of them. Tabulation is the process of arranging data in rows and columns, and classification is the process of sorting data into groups or classes. Almost every later topic in O-Level Statistics – histograms, cumulative frequency, the mean of grouped data and measures of spread – begins with a grouped frequency table, so you must be completely secure with class limits, class boundaries, class widths and mid-interval values. Examiners also set questions on completing two-way tables and calculating percentages from them, which reward careful arithmetic and clear working.

By the end of this chapter you should be able to:

  • Construct a frequency table for discrete data and a grouped frequency table for discrete or continuous data.
  • Choose suitable class intervals and explain the effect of grouping on the information retained.
  • Distinguish between class limits and class boundaries and find boundaries for discrete, rounded continuous and age data.
  • Calculate class widths and mid-interval values.
  • Complete two-way tables and calculate row and column percentages.
  • State the features of a well-constructed statistical table.
02

Why Tabulate Data?

Raw data, such as a list of sixty exam marks in the order they were recorded, are very hard to interpret. It is difficult to see the highest and lowest values, where most of the values lie or whether there are any unusual results. Arranging the data in a table condenses them into a compact form so that patterns become visible and comparisons can be made quickly.

A table also acts as the starting point for further work. Frequency tables lead directly to bar charts, histograms and frequency polygons, and grouped tables are used to estimate the mean, median and standard deviation. A well-designed table can be read by someone who has not seen the original data and still convey the main message correctly.

There is a cost, however. When data are grouped, the exact individual values are lost. We know that eight students scored between 40 and 49, but not their actual marks. This loss of detail is the price paid for clarity, and it is why statistics calculated from grouped data, such as the mean, are only estimates.

03

Ungrouped and Grouped Frequency Tables

For discrete data with only a few different values, such as the number of goals scored in a match, an ungrouped frequency table lists each value with its frequency. The values are usually written in increasing order in the first column, a tally column may follow, and the frequency column gives the count for each value. The sum of the frequencies, written Σf, equals the total number of observations.

When discrete data take many different values, such as test marks from 0 to 100, or when data are continuous, the values are grouped into classes. Generally between five and ten classes are used: too few classes hide the shape of the distribution, and too many leave some classes nearly empty so that the pattern is again unclear. Classes should not overlap and should cover every observed value. Equal class widths are usually easiest to work with, but unequal widths are sometimes sensible when data are sparse at the extremes.

Open-ended classes such as '60 and over' or 'under 10' may be used for a few extreme values, but they make calculations harder because the class has no stated end. When a calculation is required, a sensible closing value must be assumed, usually by giving the class the same width as its neighbour.

Key fact:Use 5–10 non-overlapping classes that together cover all the data.
04

Class Limits and Class Boundaries

Class limits are the smallest and largest values that can actually be recorded in a class, as written in the table. For discrete marks grouped as 20–29, 30–39, the lower class limit of the first class is 20 and the upper class limit is 29. Notice that there is a gap between 29 and 30 in the written limits, even though no mark lies in that gap.

Class boundaries close these gaps so that the classes meet. The boundary between two classes lies halfway between the upper limit of one class and the lower limit of the next. For classes 20–29 and 30–39, the boundary is (29 + 30) ÷ 2 = 29.5. So the class 20–29 has lower boundary 19.5 and upper boundary 29.5. Boundaries are essential when drawing histograms and cumulative frequency curves, because the bars and points must be placed on a continuous scale.

For continuous data that have been rounded, the boundaries come from the limits of accuracy. If masses are recorded to the nearest kilogram and one class is 45–49 kg, a mass of 44.6 kg would be recorded as 45 and a mass of 49.4 kg as 49, so the class boundaries are 44.5 kg and 49.5 kg. If the classes are written with inequalities, such as 45 ≤ m < 50, then the boundaries are simply 45 and 50.

  • Discrete 20–29: boundaries 19.5 and 29.5.
  • Nearest kg 45–49: boundaries 44.5 and 49.5.
  • Inequality 45 ≤ m < 50: boundaries 45 and 50.
  • Age in completed years 10–14: boundaries 10 and 15.
05

The Special Case of Age

Age is a common exam trap. People state their age in completed years, so a person who says they are 14 could be anywhere from exactly 14 years old up to one day short of 15. Age is not rounded to the nearest year; it is always rounded down. Therefore the class 10–14 years contains people from their 10th birthday up to, but not including, their 15th birthday, giving class boundaries of 10 and 15.

This changes the class width and mid-interval value. The class 10–14 years has width 15 − 10 = 5 years and mid-interval value (10 + 15) ÷ 2 = 12.5 years, not 12 years as it would be for rounded data. Whenever a table gives 'age last birthday' or 'age in completed years', use this rule. If the question says ages are given to the nearest year, then the usual half-unit rule applies instead.

Key fact:Age last birthday 10–14 → boundaries 10 and 15, mid-value 12.5.
06

Class Width and Mid-interval Value

The class width is the difference between the upper and lower class boundaries: class width = upper boundary − lower boundary. It is a common error to subtract the class limits instead. For the discrete class 20–29, the width is 29.5 − 19.5 = 10, not 29 − 20 = 9. The width is needed for histograms, where it determines how wide each bar is and is used to calculate frequency density.

The mid-interval value, also called the class mid-point, is the value halfway through the class: mid-interval value = (lower boundary + upper boundary) ÷ 2. For the discrete class 20–29 this is (19.5 + 29.5) ÷ 2 = 24.5, which also equals (20 + 29) ÷ 2. The mid-interval value is used to represent every observation in the class when estimating the mean and standard deviation of grouped data, and it is the x-coordinate used when plotting a frequency polygon.

For continuous data given with inequalities, such as 150 ≤ h < 160, the width is 10 and the mid-interval value is 155. For rounded continuous data, remember to use boundaries rather than limits so that your values are consistent.

Key fact:Class width = upper boundary − lower boundary. Mid-interval value = (lower boundary + upper boundary) ÷ 2.
07

Two-way Tables

A two-way table, or contingency table, shows the frequencies of two variables at the same time. The categories of one variable form the rows and the categories of the other form the columns, and each cell gives the number of individuals who belong to both categories. A final row and column give totals, and the bottom right cell gives the grand total.

Two-way tables are completed using the fact that each row and each column must add up to its total. Many exam questions give some cells and some totals and ask you to fill in the rest. Work systematically, finding any row or column that has only one missing value, filling it in, and repeating until the table is complete. Always check that the row totals and the column totals both add up to the grand total.

Percentages from a two-way table must be calculated from the correct base. The percentage of girls who travel by bus uses the girls' total as the denominator, whereas the percentage of bus travellers who are girls uses the bus total as the denominator. Reading the question carefully to identify the base is the key to these marks.

08

Features of a Good Statistical Table

A good table is self-explanatory. It has a clear, concise title stating what the data show, where and when, such as 'Masses of 50 apples picked in an orchard, June 2026'. Each column and row has a heading, and units of measurement are given in the headings rather than repeated in every cell. Totals are included where they are meaningful, and the source of the data is stated for secondary data.

Classes should be arranged in a logical order, usually increasing numerical order or, for qualitative data, alphabetical or order of size. Lines or spacing should separate the headings from the body and the totals. Numbers should be aligned and rounded consistently. A table that is cluttered, lacks units or has no title may lose marks even if the frequencies themselves are correct.

  • Clear title including what, where and when.
  • Row and column headings with units.
  • Logical order of classes.
  • Totals where meaningful.
  • Source stated for secondary data.

Key Terms

TermExam definition
TabulationThe systematic arrangement of data in rows and columns.
ClassificationThe sorting of data into groups or classes that share a common characteristic.
FrequencyThe number of times a particular value or class occurs in a set of data.
Grouped frequency tableA table showing the number of observations falling within each class interval.
Class intervalA range of values into which data are grouped, such as 20–29 or 150 ≤ h < 160.
Class limitsThe smallest and largest values that can be recorded in a class as written in the table.
Class boundariesThe values at which one class ends and the next begins, with no gaps between classes.
Class widthThe difference between the upper and lower class boundaries of a class.
Mid-interval valueThe value halfway between the lower and upper class boundaries, used to represent the class.
Open-ended classA class with no stated lower or upper limit, such as '60 and over'.
Two-way tableA table showing the frequencies of two categorical variables simultaneously, with row and column totals.
Grand totalThe total number of observations in a two-way table, equal to both the sum of row totals and the sum of column totals.

Worked Examples

Grouping raw data

The marks of 30 students are: 23, 45, 67, 34, 56, 78, 41, 52, 38, 61, 49, 55, 72, 29, 44, 58, 63, 47, 35, 51, 66, 42, 59, 70, 31, 48, 53, 64, 46, 57. Construct a grouped frequency table using classes 20–29, 30–39, 40–49, 50–59, 60–69, 70–79, and state the modal class.

  1. Go through the list once, placing a tally in the correct class for each mark.
  2. 20–29: 23, 29 gives 2. 30–39: 34, 38, 35, 31 gives 4.
  3. 40–49: 45, 41, 49, 44, 47, 42, 48, 46 gives 8. 50–59: 56, 52, 55, 58, 51, 59, 53, 57 gives 8.
  4. 60–69: 67, 61, 63, 66, 64 gives 5. 70–79: 78, 72, 70 gives 3.
  5. Check: 2 + 4 + 8 + 8 + 5 + 3 = 30. Two classes have the highest frequency of 8.
Frequencies 2, 4, 8, 8, 5, 3 (total 30). The distribution is bimodal in the sense that 40–49 and 50–59 share the highest frequency of 8, so both are modal classes.

Boundaries, widths and mid-interval values

Masses of parcels, recorded to the nearest kilogram, are grouped as 40–44, 45–49, 50–59 and 60–74. Find the class boundaries, class widths and mid-interval values.

  1. Recorded to the nearest kg, so each boundary is half a kilogram beyond the limit.
  2. 40–44: boundaries 39.5 and 44.5; width 5; mid-value (39.5 + 44.5) ÷ 2 = 42.
  3. 45–49: boundaries 44.5 and 49.5; width 5; mid-value 47.
  4. 50–59: boundaries 49.5 and 59.5; width 10; mid-value 54.5.
  5. 60–74: boundaries 59.5 and 74.5; width 15; mid-value 67.
Widths 5, 5, 10, 15 and mid-interval values 42, 47, 54.5, 67 kg, with boundaries 39.5, 44.5, 49.5, 59.5, 74.5 kg.

Completing a two-way table

120 students were asked how they travel to school. 55 are boys. 40 students walk, of whom 18 are boys. 55 students travel by bus. 12 boys travel by car. The only methods are walk, bus and car. Complete the two-way table and find the percentage of girls who travel by bus.

  1. Girls total = 120 − 55 = 65. Girls who walk = 40 − 18 = 22.
  2. Boys by bus = 55 − 18 − 12 = 25 (boys row must total 55).
  3. Girls by bus = 55 − 25 = 30. Girls by car = 65 − 22 − 30 = 13.
  4. Car total = 12 + 13 = 25. Check column totals: 40 + 55 + 25 = 120.
  5. Percentage of girls who travel by bus = (30 ÷ 65) × 100% = 46.1538%, which is 46.2% to 3 significant figures.
Boys: walk 18, bus 25, car 12. Girls: walk 22, bus 30, car 13. Totals: walk 40, bus 55, car 25, grand total 120. 46.2% of girls travel by bus.

Common Mistakes & Exam Tips

Common mistakes

  • Calculating class width from class limits, for example 29 − 20 = 9 for the class 20–29, instead of using boundaries to get 10.
  • Treating age like rounded data and giving boundaries of 9.5 and 14.5 for ages 10–14, instead of 10 and 15.
  • Using overlapping classes such as 10–20 and 20–30 for discrete data, so a value of 20 belongs to two classes.
  • Using the wrong denominator for a percentage from a two-way table; always identify which total the question refers to.
  • Forgetting to check that the frequencies add up to the total number of observations after tallying.
  • Leaving out the title or units when asked to construct a table, which can cost presentation marks.

Exam tips

  • Before any histogram, cumulative frequency or grouped mean question, write a column of class boundaries next to the table.
  • When completing a two-way table, look for a row or column with only one gap and fill that first.
  • State clearly which rule you used for boundaries (discrete, nearest unit or age) to earn method marks.
  • Show mid-interval values in a separate column; examiners award marks for them even if later arithmetic slips.
  • In percentage questions, write the fraction first, such as 30/65, before converting, so the base is visible.
  • If a class is open-ended and a calculation is needed, state the assumption you make about its width.

Model answerBoundaries 14.5 and 19.5 (1); width 5 (1).

Model answerBoundaries 149.5 cm and 154.5 cm (1). Mid-interval value = (149.5 + 154.5) ÷ 2 = 152 cm (1).

4. Ages last birthday are grouped as 20–29 years. Write down the class boundaries, class width and mid-interval value.

Model answerBoundaries 20 and 30 (1); width 10 years (1); mid-interval value 25 years (1).

5. Explain one advantage and one disadvantage of grouping data.

Model answerAdvantage: makes a large data set easier to understand and shows the pattern/distribution (1). Disadvantage: the original individual values are lost, so calculated statistics are only estimates (1).
[2 marks]

6. Find the class width and mid-interval value of the class 2.5 ≤ t < 4.0 seconds.

Model answerWidth = 4.0 − 2.5 = 1.5 s (1). Mid-interval value = (2.5 + 4.0) ÷ 2 = 3.25 s (1).
[2 marks]

7. Explain what is wrong with the classes 0–10, 10–20, 20–30 for the number of books read in a year, and suggest improved classes.

Model answerThe classes overlap: 10 and 20 each fit two classes (1). Improved: 0–9, 10–19, 20–29, 30 or more (1).
[3 marks]

8. The number of goals scored in 25 matches was: 0 1 2 1 3 0 1 2 2 1 0 4 1 2 3 1 0 2 1 1 2 0 3 1 2. Construct a frequency table.

Model answer0 goals: 5; 1 goal: 9; 2 goals: 7; 3 goals: 3; 4 goals: 1 (1 per two correct frequencies). Total = 25 (check) (1).
[2 marks]

9. In a two-way table of 200 adults, 90 are men. 70 adults prefer tea, of whom 40 are women. Find (a) the number of men who prefer tea, (b) the percentage of men who prefer tea.

Model answer(a) 70 − 40 = 30 men (1). (b) (30 ÷ 90) × 100% = 33.3% (1).
[4 marks]

10. A table shows the masses of eggs to the nearest gram in classes 50–54, 55–59, 60–64, 65–74. (a) Find the class boundaries of the class 65–74. (b) Find the width of each class. (c) Explain why a histogram cannot use equal-height bars to represent equal frequencies here.

Model answer(a) 64.5 g and 74.5 g (1). (b) 5, 5, 5, 10 g (2). (c) The class 65–74 is twice as wide as the others, so the area, not the height, must represent frequency; frequency density must be used (1).
[5 marks]

11. A survey of 150 households recorded number of cars (0, 1, 2+) and location (town, village). 100 households are in the town. 35 households have no car, of which 28 are in the town. 60 town households have 1 car. 20 village households have 2 or more cars. (a) Complete the two-way table. (b) What percentage of households with no car are in a village? (c) What percentage of village households have at least one car?

Model answer(a) Village total = 50. Village no car = 35 − 28 = 7. Village 1 car = 50 − 7 − 20 = 23. Town 2+ = 100 − 28 − 60 = 12. Column totals: no car 35, 1 car 83, 2+ cars 32; 35 + 83 + 32 = 150 (3). (b) 7 ÷ 35 × 100% = 20% (1). (c) (23 + 20) ÷ 50 × 100% = 86% (1).

Self-Assessment Quiz

14

Quick Recap

  1. Tabulating data condenses raw values into a form that shows patterns clearly, at the cost of losing individual values.
  2. Use between five and ten non-overlapping classes that cover all the data.
  3. Class limits are the written end values; class boundaries remove the gaps between classes.
  4. Boundaries depend on the data: halfway between limits for discrete data, half a unit for rounded data, and whole years for age last birthday.
  5. Class width = upper boundary − lower boundary; mid-interval value = average of the two boundaries.
  6. Two-way tables are completed using row and column totals and checked against the grand total.
  7. Percentages from two-way tables must use the correct row or column total as the base.
  8. A good table has a title, headings, units, logical order, totals and a source where needed.
