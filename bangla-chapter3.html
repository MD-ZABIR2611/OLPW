01

Overview

সন্ধি means union: when two sounds meet at the boundary of two words or word-parts, they often merge or change. Most সন্ধি in Bangla come from Sanskrit (তৎসম) words, and the same examples appear again and again in exams: হিমালয়, রবীন্দ্র, সূর্যোদয়, উচ্চারণ, মনোযোগ, নিশ্চয়. A typical question gives a word and asks you to split it (সন্ধিবিচ্ছেদ) and sometimes to name the type or state the rule. Because the rules are logical and depend on the sound classes you learned in Chapter 1, this is one of the most scoring grammar topics once practised.

By the end of this chapter you should be able to:

  • Define সন্ধি and explain how it differs from সমাস.
  • Identify the three types of সন্ধি: স্বরসন্ধি, ব্যঞ্জনসন্ধি and বিসর্গসন্ধি.
  • Apply the main rules of স্বরসন্ধি to join and split words such as হিমালয়, নরেন্দ্র, অত্যন্ত and নায়ক.
  • Apply the main rules of ব্যঞ্জনসন্ধি and বিসর্গসন্ধি, using sound classes (ঘোষ, অঘোষ, নাসিক্য).
  • Recognise common exceptions (নিপাতনে সিদ্ধ সন্ধি) such as গবাক্ষ, পরস্পর and বৃহস্পতি.
  • Write clear, mark-scheme style সন্ধিবিচ্ছেদ answers with the type of সন্ধি stated.
02

What Sandhi Is and Why It Matters

সন্ধি is the joining of two sounds that stand very close to each other, at the end of one word and the start of the next. The purpose of সন্ধি is ease of pronunciation (উচ্চারণের সহজতা) and pleasing sound (শ্রুতিমাধুর্য). Saying হিম আলয় quickly naturally produces হিমালয়; saying উৎ চারণ quickly produces উচ্চারণ. The reverse process, splitting a joined word into its original parts, is called সন্ধিবিচ্ছেদ, and it is the form in which the topic is usually examined.

Students often confuse সন্ধি with সমাস, so the difference must be clear. সন্ধি is about sounds: two sounds meet and change. সমাস is about meaning: two or more words with a meaningful relationship are combined into one, and their connecting words or endings disappear. In সন্ধি the change happens only at the meeting point of sounds; in সমাস the vital thing is the meaning relationship expressed by the ব্যাসবাক্য. For example, বিদ্যালয় is a সন্ধি of বিদ্যা + আলয় (আ + আ = আ), and it can also be analysed as a সমাস: বিদ্যার আলয় (ষষ্ঠী তৎপুরুষ). One word can therefore be studied in both ways.

Bangla has three kinds of সন্ধি. স্বরসন্ধি: a vowel meets a vowel. ব্যঞ্জনসন্ধি: a consonant meets a consonant or a vowel, or a vowel meets a consonant. বিসর্গসন্ধি: a বিসর্গ (ঃ) meets a vowel or consonant. There are also খাঁটি বাংলা সন্ধি in native words, such as কাঁচা + কলা = কাঁচকলা, ঘোড়া + দৌড় = ঘোড়দৌড়, মিশ + কালো = মিশকালো, where a vowel simply drops, but the exam mostly concentrates on তৎসম সন্ধি.

Key fact:সন্ধি joins sounds for easy pronunciation; সমাস joins words by meaning. The reverse of সন্ধি is সন্ধিবিচ্ছেদ.
03

স্বরসন্ধি (Vowel Sandhi): Merging Rules

In স্বরসন্ধি, the final vowel of the first part meets the first vowel of the second part. The simplest rule is that similar vowels merge into the long form. অ/আ + অ/আ = আ: হিম + আলয় = হিমালয়, নর + অধম = নরাধম, বিদ্যা + আলয় = বিদ্যালয়, যথা + অর্থ = যথার্থ, দেব + আলয় = দেবালয়. ই/ঈ + ই/ঈ = ঈ: অতি + ইত = অতীত, রবি + ইন্দ্র = রবীন্দ্র, সতী + ঈশ = সতীশ, পরি + ঈক্ষা = পরীক্ষা, গিরি + ঈশ = গিরীশ. উ/ঊ + উ/ঊ = ঊ: মরু + উদ্যান = মরূদ্যান, বধূ + উৎসব = বধূৎসব, লঘু + ঊর্মি = লঘূর্মি.

Different vowels combine in fixed patterns. অ/আ + ই/ঈ = এ (এ-কার): নর + ইন্দ্র = নরেন্দ্র, মহা + ঈশ = মহেশ, পরম + ঈশ্বর = পরমেশ্বর, যথা + ইষ্ট = যথেষ্ট, শুভ + ইচ্ছা = শুভেচ্ছা. অ/আ + উ/ঊ = ও (ও-কার): সূর্য + উদয় = সূর্যোদয়, যথা + উচিত = যথোচিত, মহা + উৎসব = মহোৎসব, হিত + উপদেশ = হিতোপদেশ, নব + ঊঢ়া = নবোঢ়া. অ/আ + ঋ = অর্ (রেফ): দেব + ঋষি = দেবর্ষি, মহা + ঋষি = মহর্ষি, রাজা + ঋষি = রাজর্ষি.

When অ/আ meets এ/ঐ the result is ঐ, and when it meets ও/ঔ the result is ঔ. জন + এক = জনৈক, সদা + এব = সদৈব, মত + ঐক্য = মতৈক্য, মহা + ঐশ্বর্য = মহৈশ্বর্য. বন + ওষধি = বনৌষধি, মহা + ঔষধি = মহৌষধি, পরম + ঔষধ = পরমৌষধ. These patterns follow one logic: the অ/আ of the first word disappears into a strengthened version of the second vowel.

  • অ/আ + অ/আ = আ: হিমালয়, বিদ্যালয়, যথার্থ
  • ই/ঈ + ই/ঈ = ঈ: রবীন্দ্র, পরীক্ষা, অতীত
  • উ/ঊ + উ/ঊ = ঊ: মরূদ্যান, বধূৎসব
  • অ/আ + ই/ঈ = এ: নরেন্দ্র, মহেশ, যথেষ্ট
  • অ/আ + উ/ঊ = ও: সূর্যোদয়, যথোচিত, মহোৎসব
  • অ/আ + ঋ = অর্: দেবর্ষি, মহর্ষি
  • অ/আ + এ/ঐ = ঐ: জনৈক, মতৈক্য; অ/আ + ও/ঔ = ঔ: বনৌষধি, মহৌষধি
04

স্বরসন্ধি: Vowels That Become Consonants

When ই, উ or ঋ meets a dissimilar vowel, the first vowel turns into a semi-vowel sign. ই/ঈ + another vowel = য-ফলা: অতি + অন্ত = অত্যন্ত, ইতি + আদি = ইত্যাদি, প্রতি + উপকার = প্রত্যুপকার, প্রতি + এক = প্রত্যেক, অতি + উক্তি = অত্যুক্তি, অভি + আস = অভ্যাস. উ/ঊ + another vowel = ব-ফলা: সু + অল্প = স্বল্প, সু + আগত = স্বাগত, অনু + এষণ = অন্বেষণ, অনু + ইত = অন্বিত, মনু + অন্তর = মন্বন্তর. ঋ + another vowel = র-ফলা: পিতৃ + আলয় = পিত্রালয়, পিতৃ + আদেশ = পিত্রাদেশ, মাতৃ + আদেশ = মাত্রাদেশ.

The vowels এ, ঐ, ও, ঔ, when followed by another vowel, split into a vowel plus য় or ব. এ + vowel = অয়: নে + অন = নয়ন, শে + অন = শয়ন, চে + অন = চয়ন. ঐ + vowel = আয়: নৈ + অক = নায়ক, গৈ + অক = গায়ক, বিনৈ + অক = বিনায়ক. ও + vowel = অব্: পো + অন = পবন, ভো + অন = ভবন, শ্রো + অন = শ্রবণ. ঔ + vowel = আব্: পৌ + অক = পাবক, ভৌ + উক = ভাবুক. Words like নায়ক, গায়ক and পবন look simple, which is exactly why examiners like them: many students cannot see the সন্ধি hidden inside.

When splitting a word, work backwards from the join. If you see য-ফলা after a consonant followed by a vowel, suspect ই/ঈ; if you see ব-ফলা, suspect উ/ঊ. If a word ends in -অয়ন, -আয়ক, -অবন or -আবক, look for the এ, ঐ, ও, ঔ rules. Always check that both parts are real words or roots: প্রতি + এক is right, but প্রত্য + এক is meaningless.

Key fact:ই → য-ফলা (অত্যন্ত), উ → ব-ফলা (স্বাগত), ঋ → র-ফলা (পিত্রালয়), এ → অয় (নয়ন), ঐ → আয় (নায়ক), ও → অব (পবন), ঔ → আব (পাবক).
05

ব্যঞ্জনসন্ধি (Consonant Sandhi): ৎ and Voicing Rules

Many ব্যঞ্জনসন্ধি involve খণ্ড-ত (ৎ), which is common in the prefixes উৎ and সৎ and the word তৎ. ৎ assimilates to the following consonant. ৎ + চ/ছ = চ্চ/চ্ছ: উৎ + চারণ = উচ্চারণ, সৎ + চরিত্র = সচ্চরিত্র, উৎ + ছেদ = উচ্ছেদ. ৎ + জ/ঝ = জ্জ/জ্ঝ: সৎ + জন = সজ্জন, উৎ + জ্বল = উজ্জ্বল, বিপৎ + জাল = বিপজ্জাল. ৎ + ল = ল্ল: উৎ + লাস = উল্লাস, উৎ + লেখ = উল্লেখ. ৎ + শ = চ্ছ: উৎ + শ্বাস = উচ্ছ্বাস, চলৎ + শক্তি = চলচ্ছক্তি. ৎ + হ = দ্ধ: উৎ + হার = উদ্ধার, উৎ + হত = উদ্ধত, তৎ + হিত = তদ্ধিত. ৎ + ড = ড্ড: উৎ + ডীন = উড্ডীন.

A second group follows the ঘোষ rule. When the first letter of a group (ক্, চ্, ট্, ত্, প্) is followed by a vowel or by a ঘোষ consonant (3rd or 4th letter, or য, র, ব), it becomes the third letter of its own group (গ্, জ্, ড্, দ্, ব্). দিক্ + অন্ত = দিগন্ত, বাক্ + দান = বাগ্দান, বাক্ + দেবী = বাগ্দেবী, ষট্ + আনন = ষড়ানন, সৎ + উপায় = সদুপায়, তৎ + অবধি = তদবধি, জগৎ + ঈশ = জগদীশ, ভগবৎ + গীতা = ভগবদ্গীতা, উৎ + যোগ = উদ্যোগ, উৎ + গম = উদ্গম, সুপ্ + অন্ত = সুবন্ত, অচ্ + অন্ত = অজন্ত.

When the first letter of a group is followed by a নাসিক্য (ন or ম), it becomes the nasal of its own group. দিক্ + নির্ণয় = দিঙ্নির্ণয়, বাক্ + ময় = বাঙ্ময়, জগৎ + নাথ = জগন্নাথ, উৎ + নতি = উন্নতি, তৎ + মধ্যে = তন্মধ্যে, চিৎ + ময় = চিন্ময়, মৃৎ + ময় = মৃন্ময়, উৎ + মাদ = উন্মাদ. This rule and the ঘোষ rule are simple applications of Chapter 1: an অঘোষ sound becomes ঘোষ before a voiced sound, and becomes nasal before a nasal.

  • ৎ + চ = চ্চ (উচ্চারণ); ৎ + জ = জ্জ (সজ্জন); ৎ + ল = ল্ল (উল্লাস)
  • ৎ + শ = চ্ছ (উচ্ছ্বাস); ৎ + হ = দ্ধ (উদ্ধার)
  • অঘোষ + স্বর/ঘোষ = ৩য় বর্ণ: দিগন্ত, সদুপায়, জগদীশ, উদ্যোগ
  • অঘোষ + ন/ম = নাসিক্য: জগন্নাথ, উন্নতি, মৃন্ময়
06

ব্যঞ্জনসন্ধি: ম্, ছ and Other Rules

The consonant ম্ at the end of the first part, especially in the prefix সম্, changes according to the next letter. Before a বর্গীয় consonant (ক to ম), ম্ becomes the nasal of that group or অনুস্বার. সম্ + চয় = সঞ্চয়, কিম্ + চিৎ = কিঞ্চিৎ, সম্ + তাপ = সন্তাপ, সম্ + ধান = সন্ধান, সম্ + দেশ = সন্দেশ. Before the ক-বর্গ, Bangla Academy prefers অনুস্বার: সম্ + গীত = সংগীত, সম্ + কল্প = সংকল্প, অহম্ + কার = অহংকার, সম্ + খ্যা = সংখ্যা. Before য, র, ল, ব, শ, ষ, স, হ, ম্ becomes ং: সম্ + যম = সংযম, সম্ + রক্ষণ = সংরক্ষণ, সম্ + লাপ = সংলাপ, সম্ + বাদ = সংবাদ, সম্ + শয় = সংশয়, সম্ + সার = সংসার, সম্ + হার = সংহার. The famous exception is সম্ + রাট = সম্রাট.

When a vowel is followed by ছ, the ছ becomes চ্ছ. বি + ছেদ = বিচ্ছেদ, পরি + ছেদ = পরিচ্ছেদ, অনু + ছেদ = অনুচ্ছেদ, এক + ছত্র = একচ্ছত্র, প্রতি + ছবি = প্রতিচ্ছবি. Other useful rules: ষ্ + ত/থ becomes ষ্ট/ষ্ঠ (কৃষ্ + তি = কৃষ্টি, ষষ্ + থ = ষষ্ঠ); চ্/জ্ + ন becomes ঞ (যজ্ + ন = যজ্ঞ, রাজ্ + নী = রাজ্ঞী); ৎ + ত simply doubles as ত্ত (উৎ + তপ্ত = উত্তপ্ত, উৎ + তম = উত্তম).

Some consonant sandhi do not follow any regular rule and are accepted because they have long been used; these are called নিপাতনে সিদ্ধ ব্যঞ্জনসন্ধি. The standard list: পর + পর = পরস্পর, বন + পতি = বনস্পতি, বৃহৎ + পতি = বৃহস্পতি, আ + চর্য = আশ্চর্য, তৎ + কর = তস্কর, হরি + চন্দ্র = হরিশ্চন্দ্র, গো + পদ = গোষ্পদ, ষট্ + দশ = ষোড়শ, এক + দশ = একাদশ, পতৎ + অঞ্জলি = পতঞ্জলি. Learn these as a list, because no rule will help you derive them.

Key fact:সম্ + রাট = সম্রাট is the key exception to the ম্ + র = ংর rule (compare সংরক্ষণ).
07

বিসর্গসন্ধি (Visarga Sandhi)

In বিসর্গসন্ধি, a বিসর্গ at the end of the first part meets a vowel or consonant. Grammarians distinguish two origins: স-জাত বিসর্গ (from an original স্) and র-জাত বিসর্গ (from an original র্). The most common rule: অ-কার + ঃ followed by a ঘোষ consonant (3rd, 4th, 5th letters, য, র, ল, ব, হ) becomes ও. মনঃ + যোগ = মনোযোগ, মনঃ + রম = মনোরম, তিরঃ + ধান = তিরোধান, যশঃ + লাভ = যশোলাভ, সরঃ + জ = সরোজ, তপঃ + বন = তপোবন, বয়ঃ + বৃদ্ধ = বয়োবৃদ্ধ. Before অ it also becomes ও: ততঃ + অধিক = ততোধিক.

When ই-কার or উ-কার + ঃ (and র-জাত বিসর্গ after অ) is followed by a vowel or ঘোষ consonant, the বিসর্গ becomes র্. নিঃ + আকার = নিরাকার, নিঃ + অর্থক = নিরর্থক, দুঃ + যোগ = দুর্যোগ, দুঃ + নীতি = দুর্নীতি, দুঃ + অবস্থা = দুরবস্থা, আশীঃ + বাদ = আশীর্বাদ, জ্যোতিঃ + ময় = জ্যোতির্ময়, বহিঃ + গত = বহির্গত. The র-জাত type: অন্তঃ + গত = অন্তর্গত, পুনঃ + আয় = পুনরায়, পুনঃ + জন্ম = পুনর্জন্ম. When the resulting র meets another র, the first র drops and the preceding vowel lengthens: নিঃ + রব = নীরব, নিঃ + রস = নীরস, নিঃ + রোগ = নীরোগ.

Before অঘোষ consonants, বিসর্গ changes to the sibilant of the same place. Before চ/ছ it becomes শ্: নিঃ + চয় = নিশ্চয়, নিঃ + চল = নিশ্চল, দুঃ + চিন্তা = দুশ্চিন্তা, শিরঃ + ছেদ = শিরশ্ছেদ. Before ট/ঠ it becomes ষ্: ধনুঃ + টংকার = ধনুষ্টংকার, নিঃ + ঠুর = নিষ্ঠুর. Before ত/থ it becomes স্: দুঃ + তর = দুস্তর, মনঃ + তাপ = মনস্তাপ, শিরঃ + ত্রাণ = শিরস্ত্রাণ. After ই/উ, before ক/প it becomes ষ্: নিঃ + কর = নিষ্কর, দুঃ + কর = দুষ্কর, নিঃ + পাপ = নিষ্পাপ, চতুঃ + পদ = চতুষ্পদ, আবিঃ + কার = আবিষ্কার, বহিঃ + কার = বহিষ্কার. After অ, several fixed words take স্: নমঃ + কার = নমস্কার, পুরঃ + কার = পুরস্কার, তিরঃ + কার = তিরস্কার, ভাঃ + কর = ভাস্কর.

  • অঃ + ঘোষ = ও: মনোযোগ, তপোবন, সরোজ
  • ইঃ/উঃ + স্বর/ঘোষ = র্: নিরাকার, দুর্যোগ, আশীর্বাদ
  • ঃ + চ/ছ = শ্: নিশ্চয়, দুশ্চিন্তা
  • ঃ + ট/ঠ = ষ্: নিষ্ঠুর; ঃ + ত/থ = স্: মনস্তাপ, দুস্তর
  • ইঃ/উঃ + ক/প = ষ্: নিষ্কর, আবিষ্কার, নিষ্পাপ; অঃ + ক = স্: নমস্কার, পুরস্কার
  • নিঃ + র = নী: নীরব, নীরস, নীরোগ

Exceptions and a Method for সন্ধিবিচ্ছেদ

Some স্বরসন্ধি are also নিপাতনে সিদ্ধ, meaning the result does not follow the normal rule. The most frequently set: কুল + অটা = কুলটা (not কুলাটা), গো + অক্ষ = গবাক্ষ, প্র + ঊঢ় = প্রৌঢ় (not প্রোঢ়), মার্ত + অণ্ড = মার্তণ্ড, শুদ্ধ + ওদন = শুদ্ধোদন. Similarly, the বিসর্গ simply disappears in অতঃ + এব = অতএব. By contrast, ইতঃ + মধ্যে = ইতোমধ্যে follows the regular অঃ + ঘোষ = ও rule, which is why Bangla Academy prefers the spelling ইতোমধ্যে to ইতিমধ্যে.

A reliable five-step method for সন্ধিবিচ্ছেদ saves marks. First, find the join by locating the unusual element: a long vowel, a য-ফলা or ব-ফলা, a double consonant, a রেফ, or an ং. Second, think which rule could produce that element. Third, restore the original sounds on each side. Fourth, check that both parts are genuine words, prefixes or roots. Fifth, write the answer in the standard format: whole word = first part + second part, followed by the type of সন্ধি. For example: উচ্ছ্বাস = উৎ + শ্বাস (ব্যঞ্জনসন্ধি; ৎ + শ = চ্ছ).

Finally, remember that not every word with a long vowel is a সন্ধি. নদী, পাখি and বাড়ি are simple words. The exam will give words that are genuinely formed by সন্ধি, and most of them come from the lists in this chapter. Reading the list aloud several times, and testing yourself in both directions (join and split), is the fastest way to secure these marks.

Key Terms

TermExam definition
সন্ধি (Sandhi)The joining of two closely placed sounds, usually at the end of one word and the start of the next, for easier pronunciation and pleasant sound.
সন্ধিবিচ্ছেদThe splitting of a joined word into its original parts, for example হিমালয় = হিম + আলয়.
স্বরসন্ধিSandhi in which a vowel meets a vowel: রবি + ইন্দ্র = রবীন্দ্র.
ব্যঞ্জনসন্ধিSandhi in which a consonant meets a consonant or vowel, or a vowel meets a consonant: উৎ + চারণ = উচ্চারণ.
বিসর্গসন্ধিSandhi in which a বিসর্গ meets a vowel or consonant: মনঃ + যোগ = মনোযোগ.
নিপাতনে সিদ্ধ সন্ধিSandhi that does not follow the regular rules but is accepted by long usage: গো + অক্ষ = গবাক্ষ, পর + পর = পরস্পর.
খাঁটি বাংলা সন্ধিSandhi in native Bangla words, usually by dropping a vowel: কাঁচা + কলা = কাঁচকলা.
স-জাত বিসর্গA বিসর্গ that comes from an original স্; after অ it typically becomes ও before a voiced sound (মনোরম).
র-জাত বিসর্গA বিসর্গ that comes from an original র্; it reappears as র্ before vowels and voiced sounds (পুনরায়, অন্তর্গত).
খণ্ড-ত (ৎ)A ত without its inherent vowel, common in উৎ, সৎ and তৎ; it assimilates to the next consonant in ব্যঞ্জনসন্ধি.
অনুস্বার (ং)The nasal sign that replaces ম্ before য র ল ব শ ষ স হ and, in Bangla Academy spelling, before ক-বর্গ: সংসার, সংগীত.
শ্রুতিমাধুর্যPleasantness of sound; one of the two purposes of সন্ধি alongside ease of pronunciation.

Worked Examples

Mixed সন্ধিবিচ্ছেদ practice

Split the following words and name the type of সন্ধি: নরেন্দ্র, প্রত্যেক, নায়ক, সজ্জন, সংবাদ, দুর্নীতি.

  1. নরেন্দ্র: the এ-কার suggests অ + ই. নর + ইন্দ্র = নরেন্দ্র (স্বরসন্ধি; অ + ই = এ).
  2. প্রত্যেক: the য-ফলা suggests ই + another vowel. প্রতি + এক = প্রত্যেক (স্বরসন্ধি; ই + এ = য-ফলা + এ).
  3. নায়ক: the ending -আয়ক suggests ঐ + অ. নৈ + অক = নায়ক (স্বরসন্ধি; ঐ + অ = আয়).
  4. সজ্জন: the double জ suggests ৎ + জ. সৎ + জন = সজ্জন (ব্যঞ্জনসন্ধি; ৎ + জ = জ্জ).
  5. সংবাদ: the ং before ব suggests ম্. সম্ + বাদ = সংবাদ (ব্যঞ্জনসন্ধি; ম্ + ব = ং).
  6. দুর্নীতি: the রেফ after উ-কার suggests বিসর্গ. দুঃ + নীতি = দুর্নীতি (বিসর্গসন্ধি; উঃ + ঘোষ = র্).
নর + ইন্দ্র (স্বর), প্রতি + এক (স্বর), নৈ + অক (স্বর), সৎ + জন (ব্যঞ্জন), সম্ + বাদ (ব্যঞ্জন), দুঃ + নীতি (বিসর্গ).

Joining parts into a word

Join the following using সন্ধি and state the rule: মহা + ঋষি, উৎ + হার, নিঃ + চয়, সম্ + রাট.

  1. মহা + ঋষি: আ + ঋ = অর্, the র goes above the next letter as রেফ: মহর্ষি.
  2. উৎ + হার: ৎ + হ = দ্ধ: উদ্ধার.
  3. নিঃ + চয়: বিসর্গ before চ becomes শ্: নিশ্চয়.
  4. সম্ + রাট: normally ম্ + র = ংর (as in সংরক্ষণ), but this is নিপাতনে সিদ্ধ: সম্রাট.
মহর্ষি (স্বরসন্ধি), উদ্ধার (ব্যঞ্জনসন্ধি), নিশ্চয় (বিসর্গসন্ধি), সম্রাট (নিপাতনে সিদ্ধ ব্যঞ্জনসন্ধি).

Explaining a rule in a short answer

With three examples, explain the rule by which বিসর্গ becomes ও in বিসর্গসন্ধি.

  1. State the condition: when অ-কার + বিসর্গ is followed by a ঘোষ consonant (the 3rd, 4th or 5th letter of a group, or য, র, ল, ব, হ) or by অ.
  2. State the result: the অ + ঃ combination becomes ও (ও-কার on the preceding consonant).
  3. Give examples: মনঃ + যোগ = মনোযোগ; তপঃ + বন = তপোবন; সরঃ + জ = সরোজ; ততঃ + অধিক = ততোধিক.
If অ + ঃ is followed by a voiced consonant or অ, the বিসর্গ and the অ combine into ও: মনোযোগ, তপোবন, সরোজ (and ততোধিক before অ).

Common Mistakes & Exam Tips

Common mistakes

  • Splitting into non-words: পরীক্ষা is পরি + ঈক্ষা, not পরী + ক্ষা. Always check that both parts are real words, prefixes or roots.
  • Treating a সমাস question as সন্ধি or the reverse: read the instruction; সন্ধিবিচ্ছেদ asks for sound-parts (বিদ্যা + আলয়), সমাস asks for a ব্যাসবাক্য (বিদ্যার আলয়).
  • Forgetting exceptions: সম্রাট, গবাক্ষ, পরস্পর, বৃহস্পতি, আশ্চর্য and ষোড়শ do not follow the regular rules. Memorise them as a list.
  • Writing উচ্ছ্বাস without ব-ফলা or উজ্জ্বল without the second জ or ব-ফলা: the second part (শ্বাস, জ্বল) keeps its ব-ফলা after the join.
  • Using ঙ instead of ং against Bangla Academy preference: write সংগীত, সংকল্প, অহংকার, সংখ্যা.
  • Leaving out the type of সন্ধি when asked: a correct split without the name may earn only half the marks.

Exam tips

  • Write answers in the format word = part + part (type; rule), for example উচ্চারণ = উৎ + চারণ (ব্যঞ্জনসন্ধি; ৎ + চ = চ্চ).
  • Look for the clue at the join: long vowel, য-ফলা, ব-ফলা, রেফ, doubled consonant, ং or শ/ষ/স after ই-উ.
  • Group the ৎ words (উচ্চারণ, সজ্জন, উল্লাস, উদ্ধার, উচ্ছ্বাস) and the নিঃ/দুঃ words (নিরাকার, দুর্যোগ, নিশ্চয়, নিষ্ঠুর, দুস্তর) when revising; patterns stick better than single words.
  • Revise sound classes from Chapter 1 before sandhi; the ঘোষ/অঘোষ and নাসিক্য rules become obvious.
  • Practise in both directions: join and split; exam questions may ask either.
  • If unsure between two splits, choose the one where the second part is a well-known word (আলয়, ইন্দ্র, উদয়, এক) because exam words are drawn from familiar vocabulary.

Practice Questions

[2 marks]

1. What is সন্ধি? State two purposes of সন্ধি.

Model answerসন্ধি is the joining of two closely placed sounds at the meeting point of two words or word-parts. Its purposes are ease of pronunciation (উচ্চারণের সহজতা) and pleasant sound (শ্রুতিমাধুর্য).
[3 marks]

2. How is সন্ধি different from সমাস? Use বিদ্যালয় as an example.

Model answerসন্ধি joins sounds; সমাস joins words by meaning. বিদ্যালয় as সন্ধি is বিদ্যা + আলয় (আ + আ = আ); as সমাস it is বিদ্যার আলয় (ষষ্ঠী তৎপুরুষ).
[4 marks]

3. সন্ধিবিচ্ছেদ করো: হিমালয়, রবীন্দ্র, সূর্যোদয়, মহর্ষি.

Model answerহিম + আলয়; রবি + ইন্দ্র; সূর্য + উদয়; মহা + ঋষি. All স্বরসন্ধি.
[4 marks]

4. সন্ধিবিচ্ছেদ করো: অত্যন্ত, স্বাগত, পিত্রালয়, পবন.

Model answerঅতি + অন্ত (ই + অ = য-ফলা); সু + আগত (উ + আ = ব-ফলা); পিতৃ + আলয় (ঋ + আ = র-ফলা); পো + অন (ও + অ = অব).

5. সন্ধিবিচ্ছেদ করো এবং সন্ধির নাম লেখো: উল্লাস, জগন্নাথ, দিগন্ত.

7. What is নিপাতনে সিদ্ধ সন্ধি? Give four examples with their splits.

Model answerSandhi that does not follow the regular rules but is accepted because of long use. Examples: গো + অক্ষ = গবাক্ষ; পর + পর = পরস্পর; বৃহৎ + পতি = বৃহস্পতি; সম্ + রাট = সম্রাট (also accept আ + চর্য = আশ্চর্য, ষট্ + দশ = ষোড়শ, কুল + অটা = কুলটা).
[4 marks]

8. সন্ধি করো: সম্ + সার, সম্ + চয়, বি + ছেদ, নিঃ + পাপ.

Model answerWhen খণ্ড-ত (ৎ) is followed by হ, the combination becomes দ্ধ. উৎ + হার = উদ্ধার; তৎ + হিত = তদ্ধিত (also উৎ + হত = উদ্ধত).

10. Correct any wrong splits and explain: (a) পরীক্ষা = পরী + ক্ষা (b) নায়ক = না + য়ক (c) দুরবস্থা = দুর + অবস্থা.

Model answer(a) পরি + ঈক্ষা (ই + ঈ = ঈ). (b) নৈ + অক (ঐ + অ = আয়). (c) দুঃ + অবস্থা (উঃ + স্বর = র্). Each original split is wrong because the parts are not genuine words or the rule is not shown.

Model answerই/ঈ + dissimilar vowel: ই becomes য-ফলা (ইতি + আদি = ইত্যাদি, প্রতি + উপকার = প্রত্যুপকার). উ/ঊ + dissimilar vowel: উ becomes ব-ফলা (সু + অল্প = স্বল্প, অনু + এষণ = অন্বেষণ). ঋ + dissimilar vowel: ঋ becomes র-ফলা (পিতৃ + আদেশ = পিত্রাদেশ, মাতৃ + আদেশ = মাত্রাদেশ). 12. Write a short note on বিসর্গসন্ধি covering at least four rules with examples.

Model answerPoints: (1) অঃ + ঘোষ consonant or অ = ও: মনোরম, তপোবন, ততোধিক. (2) ইঃ/উঃ + vowel or ঘোষ = র্: নিরর্থক, দুর্যোগ, জ্যোতির্ময়; র-জাত বিসর্গ also: পুনরায়, অন্তর্গত. (5) নিঃ + র = নী: নীরব, নীরোগ. Award marks for each accurate rule with a correct example.

Quick Recap

  1. সন্ধি joins neighbouring sounds for easy, pleasant pronunciation; সন্ধিবিচ্ছেদ reverses it.
  2. There are three types: স্বরসন্ধি, ব্যঞ্জনসন্ধি and বিসর্গসন্ধি.
  3. Similar vowels merge into long vowels; অ/আ + ই = এ, + উ = ও, + ঋ = অর্, + এ = ঐ, + ও = ঔ.
  4. ই, উ, ঋ before a dissimilar vowel become য-ফলা, ব-ফলা and র-ফলা; এ, ঐ, ও, ঔ become অয়, আয়, অব, আব.
  5. In ব্যঞ্জনসন্ধি, ৎ assimilates to the next consonant, অঘোষ becomes ঘোষ before voiced sounds, and becomes nasal before ন/ম.
  6. In বিসর্গসন্ধি, অঃ becomes ও before voiced sounds, ইঃ/উঃ becomes র্, and ঃ becomes শ/ষ/স before voiceless consonants.
  7. Exceptions such as সম্রাট, গবাক্ষ, পরস্পর, বৃহস্পতি and আশ্চর্য must be memorised.
  8. Always answer as word = part + part with the type of সন্ধি named.
