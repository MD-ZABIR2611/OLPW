Web, Internet & Digital Communication

CORE
SECTION 01 — CHAPTER OVERVIEW

The Modern Web

This chapter explores the difference between the Internet (the physical infrastructure) and the World Wide Web (the information accessed via the Internet). It covers web technologies, the client-server model, and how web pages are constructed using HTML, CSS, and JavaScript.

SECTION 02 — LEARNING OBJECTIVES

Chapter Goals

  • Distinguish between the Internet and the World Wide Web.
  • Explain the roles of HTML, CSS, and JavaScript.
  • Describe the Client-Server model and HTTP/HTTPS.
  • Explain the purpose of cookies and DNS.
SECTION 03 — CORE THEORY

Web Technologies

The Internet is the global network of interconnected computers and cables. The World Wide Web is the collection of web pages and documents accessed via the Internet using protocols like HTTP.

Web Development Stack

HTML (HyperText Markup Language): Structures the content (text, images, links).

CSS (Cascading Style Sheets): Controls the presentation and layout (colors, fonts).

JavaScript: Adds interactivity and dynamic behavior (pop-ups, animations).

Client-Server Model

A Client (user's web browser) requests a web page. A Server (powerful computer hosting the website) receives the request, fetches the HTML/CSS files, and sends them back to the client as an HTTP Response.

SECTION 04 — KEY DEFINITIONS

Examination Definitions

URL: Uniform Resource Locator. The web address used to find a specific resource.

HTTP: HyperText Transfer Protocol. Rules for how web pages are formatted and transmitted.

COOKIE: A small text file stored on the user's computer by the browser, used to remember login states or track browsing habits.

SECTION 07 — EXAM TECHNIQUE

Comparing Internet vs WWW

Always separate infrastructure from content. The Internet is hardware (cables, routers, servers). The WWW is software/data (websites, HTML, HTTP). The WWW relies on the Internet to function.

SECTION 08 — COMMON MISTAKES

Avoid These Errors

Mistake: Saying HTML is used to style websites.

Correction: HTML is strictly for structure. CSS is used for styling.

Mistake: Thinking HTTPS makes you completely anonymous.

Correction: HTTPS encrypts the data between client and server, preventing interception. It does not hide your IP address or identity from the server.

SECTION 09 — QUICK REVISION

Fast Facts

  • Internet = Hardware. WWW = Information.
  • HTML = Structure. CSS = Style. JS = Interactivity.
  • DNS translates URLs to IP addresses.
  • HTTPS uses SSL/TLS encryption for secure data transfer.
SECTION 10 — EXAM QUESTIONS

Test Your Knowledge

Question 1 (Standard)

Explain the difference between HTTP and HTTPS, and state why HTTPS is preferred for online banking.

2 marks: HTTP transmits data in plaintext, meaning it can be intercepted and read. HTTPS uses SSL/TLS encryption to scramble the data. This is essential for banking to protect passwords and financial details from hackers.
