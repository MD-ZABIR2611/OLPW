Logic, Boolean Algebra & Digital Circuits

CORE
SECTION 01 — CHAPTER OVERVIEW

Logical Thinking

At their lowest level, computers are made of billions of tiny switches called transistors. These switches form logic gates, which process binary signals (1s and 0s). This chapter covers Boolean logic, truth tables, and logic circuits.

SECTION 02 — LEARNING OBJECTIVES

Chapter Goals

  • Define AND, OR, NOT, NAND, NOR, and XOR gates.
  • Construct truth tables for logic circuits.
  • Write Boolean expressions from logic diagrams.
  • Identify output from given inputs.
SECTION 03 — CORE THEORY

Logic Gates

Logic gates take one or more binary inputs and produce a single binary output based on a specific rule.

Gate Rules

AND: Output is 1 only if BOTH inputs are 1.

OR: Output is 1 if AT LEAST ONE input is 1.

NOT: Inverts the input (1 becomes 0, 0 becomes 1).

XOR: Output is 1 if inputs are DIFFERENT.

NAND: The inverse of AND. Output is 1 unless both inputs are 1.

SECTION 04 — KEY DEFINITIONS

Examination Definitions

BOOLEAN: A data type or logic system that only has two values: TRUE (1) or FALSE (0).

TRUTH TABLE: A table showing the output of a logic gate or circuit for all possible input combinations.

LOGIC GATE: An electronic component that performs a boolean function on one or more binary inputs.

SECTION 07 — EXAM TECHNIQUE

Drawing Truth Tables

Always list inputs in binary counting order (00, 01, 10, 11) to ensure you don't miss or duplicate any combinations. For 3 inputs, use 000, 001, 010, 011, 100, 101, 110, 111.

SECTION 08 — COMMON MISTAKES

Avoid These Errors

Mistake: Confusing XOR and OR.

Correction: OR outputs 1 if any input is 1, including if BOTH are 1. XOR outputs 1 only if the inputs are different, so if BOTH are 1, XOR outputs 0.

SECTION 09 — QUICK REVISION

Fast Facts

  • AND = Both. OR = Either. NOT = Invert.
  • NAND = NOT AND. NOR = NOT OR.
  • XOR = Exclusive OR (inputs must differ).
  • 1 = TRUE / ON. 0 = FALSE / OFF.
