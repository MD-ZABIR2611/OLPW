Discrete Random Variables and Expectation

A discrete random variable turns an experiment into a table of values and probabilities from which exact predictions follow. Expectation tells you the long-run average, which is how examiners test fairness and profit.

Key Concepts

01

A discrete random variable X takes countable values x₁, x₂, ... with probabilities p₁, p₂, ... forming a probability distribution, and the probabilities must sum to exactly 1.

02

The expectation is E(X) = Σxp, the long-run mean value of X over many repetitions of the experiment.

03

Var(X) = E(X²) − [E(X)]² where E(X²) = Σx²p, so build a third row of x²p values before finishing.

04

For a game, expected profit = expected winnings − cost to play; the game is fair when the expected net gain is 0.

05

A probability function such as P(X = x) = kx for x = 1, 2, 3, 4 is completed by finding k from ΣP(X = x) = 1.

06

Distributions may be displayed as a table, a graph of probability against value, or an algebraic function — the rules are identical.

02

Key Terms

TermExam definition
Random variableA variable whose value is a numerical outcome of a random experiment, usually denoted by an uppercase letter such as X.
Probability distributionA table, graph or formula listing each value of a discrete random variable together with its probability, with the probabilities summing to 1.
ExpectationThe long-run average value E(X) = Σxp of a random variable, found by multiplying each value by its probability and summing.
VarianceA measure of spread of a random variable, calculated as Var(X) = E(X²) − [E(X)]², with units of the variable squared.
Fair gameA game in which the expected net gain of a player is zero, so neither player wins or loses on average over many plays.
Expected profitThe mean profit of a venture, equal to expected revenue minus cost, used to decide whether a game, policy or project is worth running.
Sum of probabilitiesThe rule that the probabilities of all possible values of a discrete random variable add to exactly 1, used to find unknown constants.
Probability functionA formula P(X = x) = f(x) giving the probability of each value of a discrete random variable, valid only when every value lies between 0 and 1.

Exam Tip

Exam tip

In any distribution question, write Σp = 1 as your first line to earn the method mark, and keep probabilities as exact fractions until the final answer.

04

Practice Questions

Structured practice — write your answer, then reveal the model.

FOUNDATION

A discrete random variable X has distribution: x = 0, 1, 2 with P(X = x) = 0.2, 0.5, 0.3. Find E(X), E(X²) and Var(X).

Model answerE(X) = Σxp = 0×0.2 + 1×0.5 + 2×0.3 = 0.5 + 0.6 = 1.1 (1). E(X²) = Σx²p = 0×0.2 + 1×0.5 + 4×0.3 = 0.5 + 1.2 = 1.7 (1). Var(X) = E(X²) − [E(X)]² = 1.7 − 1.1² = 1.7 − 1.21 = 0.49 (1). Check: Σp = 0.2 + 0.5 + 0.3 = 1 (1).
CHALLENGE

A game costs 3 dollars to play. A player wins 5 dollars with probability 0.2, 2 dollars with probability 0.3, and nothing otherwise. Determine, with reasons, whether the game is fair.

Model answerExpected winnings = 5×0.2 + 2×0.3 + 0×0.5 = 1 + 0.6 = 1.6 dollars (1). Net gains are 5 − 3 = 2, 2 − 3 = −1 and 0 − 3 = −3 dollars (1). Expected net gain = 2×0.2 + (−1)×0.3 + (−3)×0.5 = 0.4 − 0.3 − 1.5 = −1.4 dollars (1). Since the expected net gain is not 0, the game is not fair; it favours the organiser, who gains 1.4 dollars per play on average (1).
