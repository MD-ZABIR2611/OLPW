Key Concepts

01

Index number = (current value ÷ base value) × 100.

02

The base year has an index of 100.

03

Weighted indices account for importance of items.

04

The Consumer Price Index measures inflation.

02

Key Terms

TermExam definition
Index numberA figure showing change relative to a base value of 100.
Base yearThe reference year with an index of 100.
Weighted indexAn index in which items are given weights by importance.

Exam Tip
