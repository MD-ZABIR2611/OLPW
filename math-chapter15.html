Functions in Depth

Functions are machines that map inputs to outputs, and examiners test whether you can chain machines together and run them backwards. The key insight is that only one-to-one functions have inverses.

Key Concepts

01

A function maps each input in its domain to exactly one output; the set of outputs is the range.

02

The composite function fg means g first, then f, so fg(x) = f(g(x)); the order matters and fg rarely equals gf.

03

The inverse function f⁻¹ reverses f, so f⁻¹f(x) = x for every x in the domain.

04

To find an inverse, write y = f(x), swap x and y, then make y the subject.

05

A function has an inverse only when it is one-to-one; f(x) = x² fails because both 3 and −3 map to 9, so the domain must be restricted, for example to x ≥ 0.

06

The graph of f⁻¹ is the reflection of the graph of f in the line y = x, which makes domains and ranges swap roles.

02

Key Terms

TermExam definition
FunctionA rule that maps each value of the input variable to exactly one value of the output variable.
DomainThe set of all allowed input values of a function.
RangeThe set of all output values a function actually produces as the input takes every value in the domain.
Inverse functionThe function f⁻¹ that reverses f, mapping each output back to its original input so that f⁻¹f(x) = x.
Composite functionA function formed by applying one function after another, written fg(x) = f(g(x)).
One-to-one functionA function in which every output comes from exactly one input, the condition required for an inverse to exist.
Mapping diagramA diagram with two columns showing how each element of the input set is paired with its image in the output set.
ImageThe output value produced when a particular input is passed through a function.

Exam Tip

Exam tip

For inverse questions always write y = f(x) first and show the swap of x and y; for fg(2), work from the inside out with g(2) before f.

04

Practice Questions

Structured practice — write your answer, then reveal the model.

FOUNDATION

f(x) = 3x − 5 and g(x) = x². Find fg(2) and f⁻¹(7), showing your method.

Model answerfg(2) = f(g(2)) = f(2²) = f(4) = 3×4 − 5 = 12 − 5 = 7 (1). For the inverse, let y = 3x − 5, then swap: x = 3y − 5 (1). Solve: y = (x + 5)/3, so f⁻¹(x) = (x + 5)/3 (1). Hence f⁻¹(7) = (7 + 5)/3 = 12/3 = 4 (1). Check: f(4) = 7 confirms the answer (1).
CHALLENGE

Explain why f(x) = x² for all real x does not have an inverse, and describe how restricting the domain allows an inverse to be defined.

Model answerAn inverse exists only for a one-to-one function (1). Here f(3) = 9 and f(−3) = 9, so two different inputs give the same output and the reverse mapping would not know whether 9 came from 3 or −3 (1). Restricting the domain to x ≥ 0 makes f one-to-one, since every output now comes from exactly one input (1). The inverse is then f⁻¹(x) = √x with domain x ≥ 0 and range f⁻¹ ≥ 0 (1).
