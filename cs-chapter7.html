SECTION 01 — CHAPTER OVERVIEW

Writing Code

This chapter introduces the core building blocks of all programming languages. You will learn how to declare variables, use operators, and control the flow of a program using sequence, selection, and iteration.

SECTION 02 — LEARNING OBJECTIVES

Chapter Goals

  • Identify and use appropriate data types (Integer, Real, Boolean, String).
  • Use arithmetic, relational, and boolean operators.
  • Write programs using IF/ELSE and CASE statements.
  • Write programs using FOR, WHILE, and REPEAT loops.
SECTION 03 — CORE THEORY

Variables & Control Flow

A variable is a named memory location. You must assign a data type to it so the computer knows how to store it. E.g., Integer for whole numbers, Real/Float for decimals, String for text, Boolean for True/False.

Control Structures

Selection: IF condition THEN... ELSE... ENDIF. Used to branch logic.

Count-controlled Iteration: FOR i = 1 TO 10... NEXT. Runs a set number of times.

Condition-controlled Iteration: WHILE condition DO... ENDWHILE. Runs as long as the condition is true (checked at the start).

SECTION 04 — KEY DEFINITIONS

Examination Definitions

VARIABLE: A named storage location whose value can change during program execution.

CONSTANT: A named value that does not change during program execution (e.g., Pi = 3.14).

ASSIGNMENT: The process of storing a value into a variable (usually using = or ←).

SECTION 07 — EXAM TECHNIQUE

Variable Naming

Use meaningful variable names. TotalScore is clear; T or x is ambiguous. In exams, always declare variables before using them.

SECTION 08 — COMMON MISTAKES

Avoid These Errors

Mistake: Off-by-one errors in loops.

Correction: FOR i = 1 TO 4 runs 4 times (1,2,3,4). If you want 5 iterations, use FOR i = 1 TO 5. Ensure boundaries are correct.

SECTION 09 — QUICK REVISION

Fast Facts

  • Integer = Whole number. Real = Decimal.
  • String = Text (enclosed in quotes).
  • Boolean = TRUE or FALSE (1 or 0).
  • WHILE checks condition before loop; REPEAT checks after.
